\begin{fichemethode}{M1}{Situer un événement : le concept, les repères voisins, la personne, ce qui change}

\textbf{Quand l'utiliser ?} Quand l'énoncé demande de dater un événement, de le placer par
rapport à d'autres, de nommer qui en est à l'origine, ou d'expliquer ce qu'il a changé.

\textbf{Pas à pas :}
\begin{enumerate}
  \item \textbf{Rattache l'événement à l'un des quatre concepts} du programme : algorithme,
        machine, langage, données. Le Web est une application des réseaux (données qui
        circulent) ; la machine universelle est une idée sur les machines ; Python est un
        langage.
  \item \textbf{Encadre-le par deux repères que tu connais} : $1642$ (Pascaline), $1936$
        (machine universelle, Turing), $1948$ (premiers ordinateurs), $1969$ (débuts
        d'Internet), $1989$ (Web), $1991$ (Python). Un événement se situe \emph{entre} deux
        repères avant de recevoir une date exacte.
  \item \textbf{Nomme la personne ou l'équipe} et son geste : Turing \emph{formule} une idée,
        Berners-Lee \emph{invente} un service, van Rossum \emph{crée} un langage.
  \item \textbf{Dis ce qui change} par rapport au repère précédent, en une phrase : « avant,
        une machine faisait un seul calcul ; après Turing, une même machine peut exécuter
        n'importe quel programme ».
  \item \textbf{Vérifie l'ordre} : un service ne peut pas précéder ce dont il dépend. Le Web
        ($1989$) suppose Internet ($1969$) ; un langage suppose des machines pour l'exécuter.
        En Python, \lstinline{evenements == sorted(evenements, key=lambda e: e[0])} confirme
        qu'une chronologie est bien rangée.
\end{enumerate}

\textbf{Exemple rédigé.} « Le premier ordinateur à programme enregistré ». Concept :
machine. Repères : après $1936$, où Turing décrit une machine universelle, et avant $1969$.
Personne : l'équipe de Manchester, en $1948$. Ce qui change : l'idée de Turing devient un
objet réel, dont le programme est stocké en mémoire comme les données. Avec
\lstinline{evenements_entre(evenements, 1940, 1970)} on retrouve exactement deux repères
dans cette fenêtre : $1948$ et $1969$.

\textbf{Erreur fréquente.} Attribuer à Pascal l'idée de machine universelle : la Pascaline
additionne, elle n'exécute pas un programme. Ou dater le Web avant Internet, alors que le
Web est un service construit \emph{sur} le réseau.

\end{fichemethode}
