\textbf{Exercice 3} --- \textit{Documenter et présenter} \hfill (10 points)

On donne la fonction suivante, sans documentation :
\begin{python}
def compter_occurrences(liste, element):
    return sum(1 for x in liste if x == element)
\end{python}

\begin{enumerate}
  \item (2 pts) Que renvoie \lstinline{a_une_docstring(compter_occurrences)} du cours ?
        Que renvoient \lstinline{compter_occurrences([3, 1, 3, 3, 2], 3)} et
        \lstinline{compter_occurrences([], 3)} ?
  \item (4 pts) Écrire une docstring complète pour cette fonction : rôle, précondition,
        postcondition sur le résultat.
  \item (4 pts) Rédiger, en quatre points (problème, choix, difficulté, démonstration), le
        plan d'une présentation orale de deux minutes de cette fonction. La démonstration
        s'appuie sur l'un des appels de la question 1.
\end{enumerate}
