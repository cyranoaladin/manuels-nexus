\begin{exercice}{1NSI-PM-EX-003}{2}{12}
Le programme suivant plante à l'exécution :
\begin{python}
notes = {"Alice": 15, "Bob": 12, "Chloe": 18}

def afficher_note(notes, nom):
    print(nom, ":", notes[nom])

afficher_note(notes, "David")
\end{python}
\begin{enumerate}
  \item Quel type d'erreur ce programme provoque-t-il ? Quel est le message exact ?
  \item En suivant la démarche méthodique du cours, identifier précisément la cause du problème (sans se contenter de « il y a une erreur »).
  \item Proposer une correction de \lstinline{afficher_note} qui affiche un message clair (par exemple \lstinline{"Nom inconnu"}) au lieu de planter, lorsque le nom n'existe pas dans \lstinline{notes}.
\end{enumerate}
\end{exercice}
