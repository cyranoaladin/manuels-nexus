\begin{exercice}{1NSI-ARCHOS-EX-004}{2}{10}
En t'aidant du tableau des commandes de base du cours (\lstinline{mkdir}, \lstinline{touch},
\lstinline{ls}, \lstinline{rm}), écrire (en Python, via \lstinline{subprocess.run}, comme
dans le cours) la séquence de commandes qui :
\begin{enumerate}
  \item crée un dossier \lstinline{projet} ;
  \item crée dans ce dossier deux fichiers vides, \lstinline{main.py} et \lstinline{readme.md} ;
  \item liste le contenu du dossier \lstinline{projet} (vérifier que les deux fichiers y apparaissent) ;
  \item supprime le fichier \lstinline{readme.md}, puis liste à nouveau le contenu du dossier pour vérifier qu'il ne reste que \lstinline{main.py}.
\end{enumerate}
\end{exercice}
