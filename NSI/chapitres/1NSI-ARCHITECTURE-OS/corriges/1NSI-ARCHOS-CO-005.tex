\begin{corrige}{1NSI-ARCHOS-EX-005}
\textbf{1.} Le propriétaire \textbf{ne peut pas} exécuter ce fichier (troisième caractère
du premier bloc : \lstinline{-}). Le groupe \textbf{peut} le lire (\lstinline{r-----} $\to$
bloc groupe \lstinline{r--}). Les autres utilisateurs \textbf{ne peuvent pas} le lire
(dernier bloc : \lstinline{---}).

\textbf{2.} \lstinline{rw-r-----} se décompose en \lstinline{rw-} (proprietaire :
$4+2=6$), \lstinline{r--} (groupe : $4$), \lstinline{---} (autres : $0$) : notation
octale \lstinline{640}.

\textbf{3.} Non, ce fichier n'est \textbf{pas} accessible en lecture par n'importe quel
utilisateur : seuls le propriétaire et les membres du groupe peuvent le lire, les
\og autres \fg{} n'ont aucun droit. Un scénario approprié : un fichier de données
personnelles partagé au sein d'une équipe (le groupe) mais qui ne doit pas être visible par
les autres utilisateurs du système.
\end{corrige}
