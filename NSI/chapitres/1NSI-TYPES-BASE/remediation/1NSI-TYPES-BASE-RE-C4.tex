\textbf{Ce qui bloque.} Tu appliques la règle du \lstinline{or} au \lstinline{and}. Avec
\lstinline{or}, un seul opérande vrai suffit. Avec \lstinline{and}, il les faut
\textbf{tous les deux} : une seule condition remplie ne donne pas un résultat vrai.

\textbf{À retenir.} Sur $n$ variables, la table a $2^n$ lignes — trois variables, huit lignes.
Et un opérateur logique renvoie toujours un booléen, jamais \lstinline{None} :
\lstinline{None} est l'absence de valeur, pas une valeur de vérité.

\begin{exercice}{1NSI-TB-RE-C4-EX1}{1}{10}
On considère l'expression $(a \text{ and } b) \text{ or } (\text{not } a)$.
\begin{enumerate}
  \item Combien de lignes compte sa table de vérité ? Justifier avant de la dresser.
  \item Dresser la table complète, avec une colonne par sous-expression.
  \item Combien de lignes rendent l'expression vraie ? Décrire ces cas en une phrase française.
\end{enumerate}
\end{exercice}
