\begin{exercice}{1NSI-TB-EX-006}{2}{18}
Sur le Web, une couleur s'écrit \lstinline{#RRGGBB} : trois composantes rouge,
verte et bleue, chacune donnée par \textbf{deux chiffres hexadécimaux}. On
considère la couleur \lstinline{#2F80ED}.
\begin{enumerate}
  \item Convertir chacune des trois composantes en base $10$, en détaillant le
    calcul pour la première.
  \item Écrire chaque composante en base $2$ sur $8$ bits.
  \item Un graphiste assombrit la couleur en divisant chaque composante par $2$
    (division entière). Donner les trois nouvelles valeurs en base $10$, puis le
    nouveau code hexadécimal complet.
  \item Combien de couleurs différentes ce codage permet-il de représenter ?
    Justifier de deux façons : à partir des bits, puis à partir des chiffres
    hexadécimaux.
  \item Pourquoi le Web note-t-il ces couleurs en hexadécimal plutôt qu'en
    décimal ? On comparera ce que couvrent deux chiffres dans chacune des deux
    bases.
\end{enumerate}
\end{exercice}
