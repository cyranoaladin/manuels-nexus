\textbf{1.}
\begin{python}
def doublons(table, colonne):
    valeurs = [ligne[colonne] for ligne in table]
    return [v for v in set(valeurs) if valeurs.count(v) > 1]
\end{python}
\lstinline{doublons(commandes, "id")} renvoie \lstinline{["C001"]} : l'identifiant
\lstinline{"C001"} apparaît deux fois. C'est anormal car un identifiant de commande est
censé être \textbf{unique} : cela peut signaler une commande enregistrée deux fois par
erreur.
