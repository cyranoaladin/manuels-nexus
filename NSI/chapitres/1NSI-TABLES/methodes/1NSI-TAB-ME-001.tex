\begin{fichemethode}{M1}{Importer un fichier en table, puis typer chaque colonne}

\textbf{Quand l'utiliser ?} Quand l'énoncé donne un fichier CSV ou texte tabulé et demande de
le charger en Python, ou quand un calcul sur une colonne « ne marche pas » juste après un
import.

\textbf{Pas à pas :}
\begin{enumerate}
  \item \textbf{Repère le séparateur} en lisant la première ligne du fichier : une virgule
        (\lstinline{delimiter=","}, valeur par défaut) ou une tabulation
        (\lstinline{delimiter="\t"}). L'en-tête donne les noms des colonnes, qui deviendront
        les clés de chaque dictionnaire.
  \item \textbf{Charge la table} avec \lstinline{csv.DictReader} dans un bloc
        \lstinline{with open(...)}, puis convertis le lecteur en liste :
        \lstinline{table = list(lecteur)}. Tu obtiens une liste de dictionnaires, une par
        ligne du fichier.
  \item \textbf{Rappelle-toi que tout est chaîne.} Le fichier ne contient que du texte :
        \lstinline{table[0]["age"]} vaut \lstinline{"17"}, pas \lstinline{17}. Un
        \lstinline{max}, un tri ou une comparaison numérique donneront un résultat faux ou une
        erreur tant que la colonne n'est pas convertie.
  \item \textbf{Convertis colonne par colonne}, dans une boucle sur les lignes :
        \lstinline{int(...)} pour les entiers, \lstinline{float(...)} pour les décimaux. Les
        colonnes de texte restent telles quelles.
  \item \textbf{Vérifie} avec \lstinline{type(table[0]["age"])} et sur une valeur connue du
        fichier.
\end{enumerate}

\textbf{Exemple rédigé.} Un fichier texte tabulé contient
\lstinline{nom}, \lstinline{age}, \lstinline{ville} puis les lignes Lina $17$ Lyon,
Omar $16$ Nantes, Sara $9$ Pau. Après
\lstinline{csv.DictReader(fichier, delimiter="\t")}, la première ligne vaut
\lstinline|{"nom": "Lina", "age": "17", "ville": "Lyon"}| : trois chaînes. Avant conversion,
\lstinline{max(ligne["age"] for ligne in table)} renvoie \lstinline{"9"}, parce que les
chaînes se comparent caractère par caractère et que \lstinline{"9"} est « plus grand » que
\lstinline{"17"}. Après la boucle \lstinline{ligne["age"] = int(ligne["age"])}, le même
\lstinline{max} renvoie $17$.

\textbf{Erreur fréquente.} Croire que \lstinline{csv.DictReader} devine les types : il ne
convertit jamais rien. Ou convertir une seule ligne (\lstinline{table[0]}) en oubliant la
boucle sur toutes les autres.

\end{fichemethode}
