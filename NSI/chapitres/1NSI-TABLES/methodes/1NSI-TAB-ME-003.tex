\begin{fichemethode}{M3}{Trier une table avec \texttt{sorted} et une clé, sans toucher à la table}

\textbf{Quand l'utiliser ?} Quand l'énoncé demande un classement, « le premier », « le plus
grand », ou une table rangée selon une colonne.

\textbf{Pas à pas :}
\begin{enumerate}
  \item \textbf{Nomme la colonne de tri} et son type : un nombre, une chaîne ? Si la colonne
        vient d'un import et contient des nombres écrits en texte, convertis-la d'abord
        (méthode M1), sinon le tri sera alphabétique : \lstinline{"121"} passe avant
        \lstinline{"17"}, qui passe avant \lstinline{"3"}.
  \item \textbf{Écris la clé} comme une fonction qui, pour une ligne, renvoie la valeur à
        comparer : \lstinline{key=lambda ligne: ligne["temps"]}. C'est cette valeur, et non
        le dictionnaire, que \lstinline{sorted} compare.
  \item \textbf{Choisis le sens} : croissant par défaut ; ajoute \lstinline{reverse=True}
        pour décroissant. « Le meilleur temps » est le plus petit : croissant ; « la
        meilleure note » est la plus grande : décroissant.
  \item \textbf{Range le résultat dans une nouvelle variable} :
        \lstinline{classement = sorted(...)}. La table d'origine reste dans son ordre ; si
        tu veux vraiment la modifier, c'est \lstinline{table.sort(...)}, qui ne renvoie rien.
  \item \textbf{Lis la réponse} dans \lstinline{classement[0]} ou \lstinline{classement[-1]}.
\end{enumerate}

\textbf{Exemple rédigé.} Trois coureurs : Ali $52{,}3$ s (dossard \lstinline{"17"}), Nour
$48{,}9$ s (\lstinline{"3"}), Sami $50{,}1$ s (\lstinline{"121"}). Le classement par temps,
\lstinline{sorted(courses, key=lambda ligne: ligne["temps"])}, donne Nour, Sami, Ali ; la
liste \lstinline{courses} reste dans l'ordre Ali, Nour, Sami. Avec \lstinline{reverse=True}
on obtient Ali, Sami, Nour. Trier par dossard sans convertir donne \lstinline{"121"},
\lstinline{"17"}, \lstinline{"3"} : ordre alphabétique ; avec
\lstinline{key=lambda ligne: int(ligne["dossard"])} on retrouve $3$, $17$, $121$.

\textbf{Erreur fréquente.} Écrire \lstinline{tri = table.sort(...)} et obtenir
\lstinline{None}. Ou appeler \lstinline{sorted(table, ...)} sans garder le résultat, puis
lire \lstinline{table[0]} en croyant la table triée.

\end{fichemethode}
