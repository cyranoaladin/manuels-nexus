\begin{exercice}{1NSI-TAB-EX-001}{1}{12}
Une librairie stocke son inventaire dans le fichier \lstinline{livres.csv} :
\begin{console}
titre,auteur,prix,stock
Le Petit Prince,Saint-Exupery,7.5,12
1984,Orwell,9.9,5
Le Comte de Monte-Cristo,Dumas,12.0,3
\end{console}
\begin{enumerate}
  \item Écrire le code Python (avec le module \lstinline{csv}) qui importe ce fichier dans une table \lstinline{livres}.
  \item Après import, quel est le type Python de \lstinline{livres[0]["prix"]} ? Écrire le code qui convertit les colonnes \lstinline{prix} (en \lstinline{float}) et \lstinline{stock} (en \lstinline{int}) pour toutes les lignes.
  \item En déduire la valeur totale du stock (somme de \lstinline{prix * stock} pour chaque livre).
\end{enumerate}
\end{exercice}
