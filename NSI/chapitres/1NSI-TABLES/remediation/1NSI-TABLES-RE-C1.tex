\textbf{Ce qui bloque.} Tu supposes que le lecteur CSV reconnaît les nombres. Il ne
reconnaît rien : chaque valeur arrive en chaîne de caractères, et les chaînes se comparent
lettre par lettre. Un \lstinline{max}, un tri ou un \lstinline{>=} sur une colonne non
convertie donne un résultat faux, ou une erreur.

\textbf{À retenir.} Après \lstinline{csv.DictReader}, convertir explicitement chaque colonne
numérique, pour \emph{toutes} les lignes, avant tout calcul. Le fichier stocke des
caractères ; le type est une décision du programme.

\begin{exercice}{1NSI-TAB-RE-C1-EX1}{1}{10}
Le fichier \lstinline{eleves.csv} contient :
\begin{console}
nom,age
Lina,17
Omar,16
Sara,9
Tom,21
\end{console}
Un élève l'importe avec \lstinline{csv.DictReader} dans une table \lstinline{eleves}, puis
écrit :
\begin{python}
plus_age = max(ligne["age"] for ligne in eleves)
majeurs = [ligne["nom"] for ligne in eleves if ligne["age"] >= "18"]
\end{python}
\begin{enumerate}
  \item Que vaut \lstinline{plus_age} ? Que vaut \lstinline{majeurs} ? Expliquer ces deux
        résultats.
  \item L'élève remplace \lstinline{"18"} par \lstinline{18}. Que se passe-t-il ?
  \item Corriger le programme pour obtenir l'âge maximal et la liste des majeurs attendus.
\end{enumerate}
\end{exercice}
