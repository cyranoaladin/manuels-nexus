\begin{exercice}{1NSI-TC-EX-021}{2}{10}
On considère la fonction suivante :
\begin{python}
def decaler(tab):
    dernier = tab[-1]
    for i in range(len(tab) - 1, 0, -1):
        tab[i] = tab[i - 1]
    tab[0] = dernier

scores = [10, 20, 30, 40]
decaler(scores)
print(scores)
\end{python}

  \item Décrire en une phrase le rôle de cette fonction.
  \item La fonction renvoie-t-elle une valeur ? Comment le tableau est-il modifié ?
\end{enumerate}
\end{exercice}
