\begin{exercice}{1NSI-TC-EX-022}{1}{8}
Compléter la trace du programme suivant, qui affiche les élèves ayant la moyenne :
\begin{python}
eleves = ["Alice", "Bob", "Clara"]
notes = [14, 8, 17]
for i in range(len(eleves)):
    if notes[i] >= 10:
        print(eleves[i], ":", notes[i])
\end{python}
\begin{enumerate}
  \item Donner les affichages produits.
  \item Quel est le lien entre les deux tableaux \lstinline{eleves} et \lstinline{notes} ?
  \item Pourquoi utilise-t-on \lstinline{range(len(eleves))} plutôt que
        \lstinline{for e in eleves} ?
\end{enumerate}
\end{exercice}
