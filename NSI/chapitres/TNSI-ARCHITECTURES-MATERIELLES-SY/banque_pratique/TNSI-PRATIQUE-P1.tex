\subsection*{Réponse attendue à la question 5}

Quand le quantum dépasse le plus grand besoin, aucun processus n'est jamais
remis en file : chacun s'exécute d'un seul tenant, dans l'ordre d'entrée. Le
tourniquet dégénère en « premier arrivé, premier servi ».

\subsection*{Critique}

\begin{itemize}
  \item \textbf{Remettre en file un processus terminé.} La file ne se vide
    jamais et la boucle ne s'arrête pas. C'est la panne la plus fréquente, et
    elle se manifeste par un blocage, pas par un résultat faux.
  \item \textbf{Compter les instants à partir de $0$.} Tous les instants de fin
    sont alors décalés de $1$, et le jeu de tests échoue en bloc — ce qui est
    préférable à un échec partiel.
  \item \textbf{Écrire les préconditions en commentaire.} La question 2 exige
    qu'elles soient exécutables : un commentaire ne refuse aucun appel.
\end{itemize}
