\begin{exercice}{1NSI-AGT-RE-C5-EX1}{1}{10}
Un élève écrit le tri par sélection suivant, mais place l'initialisation de
\lstinline{indice_min} à l'\textbf{intérieur} de la boucle \lstinline{for} interne au lieu
de l'externe :
\begin{python}
def tri_selection_bugue(tableau):
    tableau = tableau[:]
    n = len(tableau)
    for i in range(n - 1):
        for j in range(i + 1, n):
            indice_min = i  # reinitialise a CHAQUE tour de la boucle interne
            if tableau[j] < tableau[indice_min]:
                indice_min = j
        tableau[i], tableau[indice_min] = tableau[indice_min], tableau[i]
    return tableau
\end{python}
\begin{enumerate}
  \item Tester cette fonction sur \lstinline{[9, 1, 5, 3, 7]}. Le résultat est-il correctement trié ?
  \item Expliquer précisément pourquoi replacer \lstinline{indice_min = i} à l'intérieur de la boucle \lstinline{for j} empêche l'algorithme de retenir le minimum \textbf{global} de la partie restante.
  \item Corriger le code en plaçant l'initialisation au bon endroit.
\end{enumerate}
\end{exercice}
