\begin{exercice}{1NSI-APT-EX-102}{1}{15}
Un élève écrit la recherche du maximum en initialisant l'accumulateur à zéro :
\begin{python}
def maximum_bugue(tableau):
    plus_grand = 0
    for element in tableau:
        if element > plus_grand:
            plus_grand = element
    return plus_grand
\end{python}
\begin{enumerate}
  \item Cette fonction donne le bon résultat sur \lstinline{[4, 9, 2]}. Le vérifier.
  \item L'appliquer à \lstinline{[-7, -3, -12]}. Quel résultat obtient-on ? Pourquoi est-il
    inacceptable, alors même qu'aucune erreur n'est signalée ?
  \item Corriger l'initialisation, et expliquer pourquoi la valeur de départ doit
    \textbf{provenir du tableau}.
  \item Que se passe-t-il si le tableau est vide, avec la version corrigée ? Ajouter le
    traitement de ce cas.
  \item Écrire \lstinline{moyenne(tableau)}. Vérifier que la moyenne de \lstinline{[4, 5]}
    vaut $4.5$ et non $4$ : quelle erreur d'opérateur produirait $4$ ?
\end{enumerate}
\end{exercice}
