\section*{Évaluation A --- Parcours et tris}
\textit{Durée : 45 minutes. Ordinateur avec interpréteur Python autorisé.}

\baremeIndicatif{Ex. 1 : 6 pts (recherche, extremum, moyenne) ; Ex. 2 : 7 pts (tri par insertion, invariant) ; Ex. 3 : 7 pts (tri par sélection, invariant)}

\bigskip

\textbf{Exercice 1} --- \textit{Parcours séquentiel} \hfill (6 points)

On donne le tableau \lstinline{[22, 15, 8, 30, 11]}.

\begin{enumerate}
  \item (2 pts) À quel indice se trouve la valeur $30$ ? Utiliser \lstinline{recherche_occurrence} du cours.
  \item (2 pts) Calculer le maximum de ce tableau avec \lstinline{maximum}. Expliquer pourquoi l'accumulateur ne peut pas être initialisé à $0$ si le tableau peut contenir des valeurs négatives.
  \item (2 pts) Calculer la moyenne de ce tableau avec \lstinline{moyenne}. Détailler le calcul à la main.
\end{enumerate}

\bigskip

\textbf{Exercice 2} --- \textit{Tri par insertion} \hfill (7 points)

On applique le tri par insertion au tableau \lstinline{[9, 2, 6, 4]}.

\begin{enumerate}
  \item (4 pts) Dérouler l'algorithme : donner le contenu du tableau après chaque itération de la boucle externe.
  \item (2 pts) Énoncer l'invariant de la boucle externe en bornant la zone concernée, et le vérifier à chaque étape.
  \item (1 pt) Quel est le coût de cet algorithme dans le pire cas, en fonction de la taille $n$ du tableau ?
\end{enumerate}

\bigskip

\textbf{Exercice 3} --- \textit{Tri par sélection} \hfill (7 points)

Le code suivant est incomplet : les deux lignes marquées \lstinline{...} sont à écrire.

\begin{python}
def tri_selection(tableau):
    tableau = tableau[:]
    n = len(tableau)
    for i in range(n - 1):
        ...                     # (a) initialiser le candidat minimum
        for j in range(i + 1, n):
            if tableau[j] < tableau[indice_min]:
                ...             # (b) mettre a jour le candidat
        tableau[i], tableau[indice_min] = tableau[indice_min], tableau[i]
    return tableau
\end{python}

\begin{enumerate}
  \item (3 pts) Écrire les deux lignes manquantes.
  \item (2 pts) L'invariant du tri par sélection comporte \textbf{deux} clauses. Les énoncer toutes les deux.
  \item (2 pts) L'une de ces deux clauses est fausse pour le tri par insertion. Laquelle, et pourquoi ? Illustrer avec le tableau de l'exercice 2.
\end{enumerate}
