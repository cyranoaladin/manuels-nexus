\begin{exercice}{1NSI-LANG-EX-002}{1}{12}
On donne le code suivant, écrit dans un langage de style C, qui calcule la factorielle d'un
entier \lstinline{n} :
\begin{console}
int factorielle(int n) {
    int resultat = 1;
    for (int i = 1; i <= n; i = i + 1) {
        resultat = resultat * i;
    }
    return resultat;
}
\end{console}
\begin{enumerate}
  \item Traduire ce code en Python (fonction \lstinline{factorielle(n)}).
  \item Identifier deux traits \textbf{communs} entre les deux écritures, et deux traits \textbf{particuliers} au langage de style C (absents en Python).
  \item Vérifier que \lstinline{factorielle(5)} vaut $120$ et que \lstinline{factorielle(0)} vaut $1$.
\end{enumerate}
\end{exercice}
