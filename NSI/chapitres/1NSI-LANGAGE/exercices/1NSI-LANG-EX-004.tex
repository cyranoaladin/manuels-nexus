\begin{exercice}{1NSI-LANG-EX-004}{2}{12}
Un élève teste sa fonction \lstinline{est_premier_bugue} uniquement sur $7$ (nombre
premier) et $8$ (non premier), et conclut qu'elle est correcte :
\begin{python}
def est_premier_bugue(n):
    for i in range(2, n):
        if n % i == 0:
            return False
    return True

print(est_premier_bugue(7))  # True
print(est_premier_bugue(8))  # False
\end{python}
\begin{enumerate}
  \item Que renvoie \lstinline{est_premier_bugue(1)} ? Est-ce le résultat attendu ($1$ n'est pas un nombre premier) ?
  \item Pourquoi le jeu de tests de l'élève (seulement $7$ et $8$) n'a-t-il pas permis de détecter ce bug ?
  \item Corriger la fonction, et proposer un jeu de tests plus complet (au moins $4$ cas, dont un cas limite) qui aurait détecté le bug.
\end{enumerate}
\end{exercice}
