\begin{exercice}{1NSI-LANG-EX-006}{2}{20}
Une caisse automatique est programmée dans un langage à accolades, différent de
Python. Voici la fonction qui calcule le total d'un panier en ignorant les
lignes de montant négatif (retours d'articles saisis à part) :
\begin{console}
function totalPanier(prix) {
    let total = 0;
    for (let i = 0; i < prix.length; i = i + 1) {
        if (prix[i] > 0) {
            total = total + prix[i];
        }
    }
    return Math.round(total * 100) / 100;
}
\end{console}
\begin{enumerate}
  \item Repérer dans ce code une occurrence de chacune des constructions
    élémentaires suivantes : séquence, affectation, boucle bornée,
    conditionnelle, appel de fonction. Citer la ligne concernée à chaque fois.
  \item Traduire cette fonction en Python, sous le nom
    \lstinline{total_panier(prix)}.
  \item Tester la traduction sur \lstinline{[3.5, -1, 2.0, 4.25]} (résultat
    attendu : $9{,}75$), puis sur la liste vide et sur
    \lstinline{[-2, -8]}. Que renvoie-t-elle dans ces deux derniers cas, et
    est-ce le comportement souhaitable pour une caisse ?
  \item Le langage d'origine impose \lstinline{let} et des accolades, Python
    utilise l'indentation. S'agit-il d'une différence de \emph{construction} ou
    de \emph{syntaxe} ? Justifier en une phrase.
  \item Parmi les constructions élémentaires du cours, laquelle n'apparaît pas
    dans ce code ? Donner un cas où la caisse en aurait besoin.
\end{enumerate}
\end{exercice}
