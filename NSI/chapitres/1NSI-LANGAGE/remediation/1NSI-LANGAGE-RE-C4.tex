\begin{exercice}{1NSI-LANG-RE-C4-EX1}{1}{10}
Un élève écrit une fonction censée renvoyer le \textbf{minimum} d'une liste de nombres :
\begin{python}
def minimum_bugue(liste):
    mini = 0
    for x in liste:
        if x < mini:
            mini = x
    return mini
\end{python}
\begin{enumerate}
  \item Que renvoie \lstinline{minimum_bugue([5, 3, 8])} ? Est-ce le résultat attendu ?
  \item Pourquoi cette fonction se trompe-t-elle sur cet exemple, alors que tous les éléments de la liste sont positifs ?
  \item Corriger la fonction en initialisant l'accumulateur correctement.
\end{enumerate}
\end{exercice}
