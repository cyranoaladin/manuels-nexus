\section*{QCM d'auto-évaluation --- Langages et programmation}

\begin{center}
\textit{Pour chaque question, une seule réponse est exacte. Entourez la lettre correspondante.}
\end{center}

\bigskip

\subsection*{C1 --- Constructions élémentaires}

\begin{enumerate}

\item \textbf{[Q1]} Une boucle \lstinline{while} est dite « non bornée » car :
  \begin{enumerate}[label=\Alph*.]
    \item elle ne peut jamais se terminer.
    \item le nombre d'itérations n'est pas forcément connu à l'avance.
    \item elle ne contient jamais de condition.
    \item elle est plus rapide qu'une boucle \lstinline{for}.
  \end{enumerate}

\bigskip

\subsection*{C2 --- Diversité et unité des langages}

\item \textbf{[Q2]} Ce qui varie principalement d'un langage de programmation impératif à un autre, c'est :
  \begin{enumerate}[label=\Alph*.]
    \item le noyau de constructions élémentaires (qui est différent à chaque fois).
    \item la syntaxe et des traits particuliers comme le typage.
    \item le fait qu'un même algorithme ne puisse s'écrire que dans un seul langage.
    \item rien : tous les langages sont strictement identiques.
  \end{enumerate}

\bigskip

\subsection*{C3 --- Spécification}

\item \textbf{[Q3]} Une précondition d'une fonction porte sur :
  \begin{enumerate}[label=\Alph*.]
    \item le résultat renvoyé par la fonction.
    \item les arguments passés à la fonction.
    \item le nom de la fonction.
    \item le nombre de lignes de code de la fonction.
  \end{enumerate}

\bigskip

\subsection*{C4 --- Mise au point}

\item \textbf{[Q4]} Un jeu de tests entièrement réussi :
  \begin{enumerate}[label=\Alph*.]
    \item prouve que le programme est correct dans tous les cas.
    \item montre seulement que le programme fonctionne sur les cas testés.
    \item garantit l'absence de tout bug futur.
    \item n'a aucun intérêt si le programme compile.
  \end{enumerate}

\bigskip

\subsection*{C5 --- Bibliothèques}

\item \textbf{[Q5]} Avant d'utiliser une fonction inconnue d'une bibliothèque, il est recommandé de :
  \begin{enumerate}[label=\Alph*.]
    \item deviner son comportement à partir de son nom.
    \item consulter sa documentation (docstring, \lstinline{help(...)}).
    \item recopier son code source avant de l'utiliser.
    \item l'essayer uniquement sur des cas limites.
  \end{enumerate}

\bigskip

\item \textbf{[Q6]} Le programme officiel de NSI Première, concernant les bibliothèques, exige :
  \begin{enumerate}[label=\Alph*.]
    \item une connaissance exhaustive d'au moins une bibliothèque.
    \item de savoir chercher et lire une documentation pour trouver la bonne fonction.
    \item de ne jamais utiliser de bibliothèque externe.
    \item de mémoriser toutes les fonctions du module \lstinline{math}.
  \end{enumerate}

\end{enumerate}
