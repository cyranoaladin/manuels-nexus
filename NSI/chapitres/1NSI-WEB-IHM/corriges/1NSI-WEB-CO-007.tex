\begin{corrige}{1NSI-WEB-EX-001}
\textbf{1.} Trois composants : le champ de texte \lstinline{champ_pseudo}, la liste
déroulante \lstinline{liste_note}, le bouton \lstinline{bouton_envoyer}.

\textbf{2.} Champ de texte : événement de \textbf{saisie} (l'utilisateur tape du texte).
Liste déroulante : événement de \textbf{changement} (l'utilisateur choisit une option).
Bouton : événement de \textbf{clic} (ou de soumission du formulaire).

\textbf{3.} Non. Le code HTML décrit uniquement la \textbf{structure} et l'\textbf{apparence}
des composants ; il ne contient \textbf{aucun} gestionnaire d'événement. Sans code
JavaScript associant une fonction à l'événement clic du bouton, rien de particulier ne se
produit à part la soumission par défaut du formulaire (rechargement de la page).
\end{corrige}
