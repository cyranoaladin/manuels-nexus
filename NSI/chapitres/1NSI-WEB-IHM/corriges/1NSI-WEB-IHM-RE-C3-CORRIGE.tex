\begin{corrige}{1NSI-WEB-IHM-RE-C3}
\begin{enumerate}
  \item \lstinline{compteur["valeur"]} vaut déjà \lstinline{1} : les parenthèses ont appelé
        \lstinline{incrementer} au moment de l'enregistrement, avant tout clic.
  \item \lstinline{declencher_clic("bouton")} ne renvoie rien d'utile : ce qui a été associé au
        bouton n'est pas une fonction mais l'entier \lstinline{1}. Il n'y a rien à exécuter,
        le bouton est inerte.
  \item Il faut retirer les parenthèses :
        \begin{python}
ajouter_gestionnaire("bouton", incrementer)
        \end{python}
        Le compteur valant déjà $1$, les trois clics renvoient alors
        \lstinline{2}, \lstinline{3}, puis \lstinline{4}.
\end{enumerate}
