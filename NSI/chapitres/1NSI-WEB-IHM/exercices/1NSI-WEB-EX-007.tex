\begin{exercice}{1NSI-WEB-EX-007}{1}{15}
Un utilisateur se connecte à un site. Voici, dans le désordre, sept actions qui
se produisent :
\begin{enumerate}
  \item[(a)] recherche du compte dans la base de données ;
  \item[(b)] mémorisation du cookie de session ;
  \item[(c)] vérification du format de l'adresse e-mail saisie ;
  \item[(d)] création du cookie de session ;
  \item[(e)] affichage de la page d'accueil personnalisée ;
  \item[(f)] vérification du mot de passe ;
  \item[(g)] envoi de la requête HTTP.
\end{enumerate}
\begin{enumerate}
  \item Dresser un tableau à deux colonnes, \emph{client} et \emph{serveur}, et y
    placer chacune des sept actions. Combien en compte chaque colonne ?
  \item Remettre les sept actions dans leur ordre d'exécution.
  \item En reprenant le modèle de cookies du cours, écrire les deux appels qui
    simulent la création du cookie \lstinline{"id_session"} de valeur
    \lstinline{"a7f3"} par le serveur, puis la requête suivante vers
    \lstinline{/profil}. Donner le dictionnaire renvoyé.
  \item Donner le dictionnaire renvoyé par une requête vers
    \lstinline{/connexion} envoyée \emph{avant} toute connexion. Qu'est-ce qui
    distingue les deux résultats ?
  \item Le mot de passe est-il mémorisé dans le client et retransmis à chaque
    requête ? Vérifier sur le contenu de \lstinline{cookies_client}, et dire
    quelle serait la conséquence si c'était le cas.
\end{enumerate}
\end{exercice}
