% FICHE DE REMEDIATION — C8 : POST deplace, HTTPS chiffre
%---------------------------------------------------------------

\textbf{Ce qui bloque.} Tu crois que POST chiffre. Il ne chiffre rien : il déplace les
paramètres de l'URL vers le \textbf{corps} de la requête. Seul HTTPS chiffre — et il chiffre
GET comme POST. C'est une confusion fréquente et lourde de conséquences.

\textbf{À retenir.} GET inscrit les paramètres dans l'URL, après un \lstinline{?} et séparés
par \lstinline{&} : ils se retrouvent dans l'historique, les favoris et les journaux du
serveur. POST les met dans le corps : ils n'apparaissent pas dans l'URL, et leur volume n'est
pas limité par la longueur d'une adresse.

\begin{exercice}{1NSI-WEB-RE-C8-EX1}{1}{10}
Un formulaire transmet \lstinline|{"identifiant": "leila", "mdp": "Ete2026"}|.
\begin{enumerate}
  \item Avec \lstinline{urlencode}, écrire l'URL produite si la méthode est GET, l'action étant
        \lstinline{/connexion}.
  \item Écrire ce que transporte le corps de la requête si la méthode est POST.
  \item Le mot de passe est-il chiffré dans le second cas ? Qu'est-ce qui le chiffrerait ?
\end{enumerate}
\end{exercice}
