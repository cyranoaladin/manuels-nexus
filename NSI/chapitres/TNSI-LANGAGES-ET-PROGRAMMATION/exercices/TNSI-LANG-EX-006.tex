\begin{exercice}{TNSI-LANG-EX-006}{2}{30}
On considère un langage jouet à quatre instructions, dont les variables sont des
entiers :
\begin{itemize}
  \item \lstinline{("SET", v, k)} affecte l'entier \lstinline{k} à la variable
    \lstinline{v} ;
  \item \lstinline{("ADD", v, w)} ajoute à \lstinline{v} la valeur de
    \lstinline{w} ;
  \item \lstinline{("DEC", v)} diminue \lstinline{v} de $1$ ;
  \item \lstinline{("TANTQUE", v, corps)} répète le sous-programme
    \lstinline{corps} tant que \lstinline{v} n'est pas nul.
\end{itemize}
\begin{enumerate}
  \item Écrire en Python l'interpréteur \lstinline{executer(programme, memoire)}
    de ce langage. Il prend une liste d'instructions et un dictionnaire, et
    renvoie l'état final de la mémoire.
  \item Écrire, \textbf{dans le langage jouet}, le programme qui calcule dans la
    variable \lstinline{s} la somme des entiers de $1$ à \lstinline{n}. Donner
    l'état de la mémoire après exécution pour $n=5$.
  \item Écrire la même fonction en Python, puis vérifier que les deux versions
    coïncident pour tous les $n$ de $0$ à $10$.
  \item Le langage jouet n'a ni fonction, ni liste, ni chaîne de caractères, et
    quatre instructions en tout. Que montre pourtant la question précédente sur
    ce qu'il est capable de calculer ? Quelle est la portée de cette remarque
    pour la notion de calculabilité ?
  \item Écrire un programme du langage jouet qui ne s'arrête jamais. Un tel
    programme existe-t-il aussi en Python ?
  \item Supposons qu'il existe une fonction Python \lstinline{arrete(source, x)}
    qui, pour \emph{toute} source de fonction et toute entrée, renvoie
    \lstinline{True} si l'exécution s'arrête et \lstinline{False} sinon. On
    définit alors
    \begin{python}
def diagonale(source):
    if arrete(source, source):
        while True:
            pass
    return "fini"
    \end{python}
    Étudier ce que fait \lstinline{diagonale} appliquée à sa propre source, dans
    les deux cas possibles. Conclure sur l'existence de \lstinline{arrete}.
  \item Cette conclusion vaudrait-elle encore si l'on remplaçait Python par le
    langage jouet ? Par n'importe quel autre langage ? Justifier en une phrase.
\end{enumerate}
\end{exercice}
