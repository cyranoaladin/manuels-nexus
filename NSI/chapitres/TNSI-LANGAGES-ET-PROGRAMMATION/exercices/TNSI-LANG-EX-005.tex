\begin{exercice}{TNSI-LANG-EX-005}{2}{20}
Le cours affirme que tout programme est aussi une donnée. Cet exercice le met à
l'épreuve. On dispose des trois fonctions
\begin{python}
def double(n):
    return 2 * n

def carre(n):
    return n * n

def incrementer(n):
    return n + 1
\end{python}
\begin{enumerate}
  \item Écrire \lstinline{appliquer(f, x)} qui renvoie \lstinline{f(x)}. Que vaut
    \lstinline{appliquer(carre, 5)} ? Quel est ici le \emph{type} du premier
    argument ?
  \item Construire la liste \lstinline{operations} contenant les trois fonctions,
    puis donner la liste des résultats de leur application à $5$. Une liste peut
    donc contenir des programmes : qu'est-ce que cela signifie ?
  \item Écrire \lstinline{composer(f, g)} qui renvoie une \textbf{nouvelle
    fonction} $x\mapsto f(g(x))$. Calculer l'image de $3$ par
    \lstinline{composer(carre, double)} puis par \lstinline{composer(double, carre)}.
    Les deux résultats coïncident-ils ? Conclure sur l'ordre.
  \item On stocke maintenant un programme dans une chaîne de caractères :
    \begin{python}
source = "def triple(n):\n    return 3 * n\n"
    \end{python}
    Donner le type et la longueur de \lstinline{source}. Utiliser
    \lstinline{exec(source, espace)} avec un dictionnaire \lstinline{espace}
    initialement vide, puis appeler la fonction ainsi définie sur $7$.
  \item Un compilateur est un programme dont l'\emph{entrée} est un programme.
    Citer deux autres logiciels dans ce cas, et dire à chaque fois ce qu'ils
    produisent en sortie.
\end{enumerate}
\end{exercice}
