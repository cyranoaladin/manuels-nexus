\begin{fichemethode}{M1}{Découper, numéroter, réassembler --- puis lire une encapsulation de l'extérieur vers l'intérieur}

\textbf{Quand l'utiliser ?} Quand l'énoncé demande combien de paquets un message produit, ce
qu'ils contiennent, si un message est reconstitué correctement, ou ce qu'un routeur « voit »
d'un paquet.

\textbf{Pas à pas --- les paquets :}
\begin{enumerate}
  \item \textbf{Compte d'abord les paquets} avec la division arrondie vers le haut :
        $\lceil \text{longueur} / \text{taille} \rceil$, soit en Python
        \lstinline{(len(message) + taille_max - 1) // taille_max}. Le dernier paquet est en
        général plus court : c'est normal, ne le « complète » pas.
  \item \textbf{Découpe en lisant} : le paquet $i$ contient les caractères d'indice
        $i \times \text{taille}$ à $(i+1) \times \text{taille} - 1$. Écris chaque tranche entre
        guillemets avec son numéro.
  \item \textbf{Réassemble par le numéro, jamais par l'ordre d'arrivée} : range les paquets
        reçus selon leur champ \lstinline{numero}, puis concatène. Si l'énoncé donne un ordre
        d'arrivée, c'est un piège volontaire : il ne change rien au résultat.
  \item \textbf{Vérifie} que le message reconstitué a la longueur du message initial.
\end{enumerate}

\textbf{Pas à pas --- l'encapsulation :}
\begin{enumerate}
  \item Un paquet encapsulé est un dictionnaire dont la clé \lstinline{donnees} contient
        \emph{un autre} dictionnaire. \textbf{Lis-le de l'extérieur vers l'intérieur} : en-tête
        réseau, puis en-tête de transport, puis les données.
  \item Pour dire ce qu'une machine intermédiaire utilise, \textbf{arrête-toi à la couche qui
        la concerne} : un routeur lit l'adresse de destination dans l'en-tête réseau et ne
        décode pas ce qui est en dessous.
\end{enumerate}

\textbf{Exemple rédigé.} Le message \lstinline{"NEXUSRESEAU"} a $11$ caractères ; avec
$\text{taille} = 4$ on obtient $\lceil 11/4 \rceil = 3$ paquets : \lstinline{"NEXU"} (numéro
$0$), \lstinline{"SRES"} (numéro $1$) et \lstinline{"EAU"} (numéro $2$, plus court). S'ils
arrivent dans l'ordre $1, 2, 0$, on les range par numéro : $0, 1, 2$, et l'on retrouve
\lstinline{"NEXUSRESEAU"}, $11$ caractères. Si le paquet \lstinline{"NEXU"} est encapsulé
avec l'en-tête de transport \lstinline|{"port": 80}| puis l'en-tête réseau
\lstinline|{"ip_dest": "10.0.0.7"}|, un routeur ne lit que \lstinline{"10.0.0.7"} ; le port
$80$ et le texte \lstinline{"NEXU"} sont « à l'intérieur », il ne les regarde pas.

\textbf{Erreur fréquente.} Concaténer les paquets dans l'ordre où ils sont listés dans
l'énoncé. Ou compter les paquets par une division entière simple, qui oublie le dernier
paquet incomplet : $11 // 4$ donne $2$, il en faut $3$.

\end{fichemethode}
