\begin{fichemethode}{M2}{Dérouler le bit alterné dans un tableau à quatre colonnes}

\textbf{Quand l'utiliser ?} Quand l'énoncé donne une liste de messages et des numéros de
tentatives perdues, et demande ce que reçoit le destinataire, avec quels bits, ou combien
de tentatives ont été nécessaires.

\textbf{Pas à pas :}
\begin{enumerate}
  \item \textbf{Dresse un tableau} à quatre colonnes : numéro de tentative, message envoyé,
        bit, résultat (reçu ou perdu). Une ligne par tentative, en commençant à $1$ avec le
        bit $0$.
  \item \textbf{Regarde d'abord la colonne « perdu »} : le numéro de la tentative est dans
        l'ensemble des pertes ? Alors la ligne est perdue et \textbf{la ligne suivante répète
        le même message avec le même bit}. Le bit ne bouge pas tant que le message n'est pas
        passé.
  \item \textbf{Alterne le bit seulement après une ligne « reçu »} : $0$ devient $1$, $1$
        devient $0$, et l'on passe au message suivant.
  \item \textbf{Conclus} en lisant les lignes « reçu » de haut en bas : ce sont, dans
        l'ordre, les couples (bit, message) reçus. Le nombre de lignes du tableau est le
        nombre de tentatives ; il vaut le nombre de messages plus le nombre de pertes.
\end{enumerate}

\textbf{Exemple rédigé.} Messages \lstinline{["A", "B", "C", "D"]}, tentatives perdues
$\{2, 3\}$. Tentative $1$ : \lstinline{"A"}, bit $0$, reçu. Tentative $2$ : \lstinline{"B"},
bit $1$, perdu. Tentative $3$ : encore \lstinline{"B"}, encore bit $1$, perdu. Tentative $4$ :
encore \lstinline{"B"}, bit $1$, reçu. Tentative $5$ : \lstinline{"C"}, bit $0$, reçu.
Tentative $6$ : \lstinline{"D"}, bit $1$, reçu. Le destinataire obtient
\lstinline{[(0, "A"), (1, "B"), (0, "C"), (1, "D")]} en $6$ tentatives : $4$ messages plus
$2$ pertes.

\textbf{Erreur fréquente.} Changer le bit à chaque tentative, y compris après une perte.
Le récepteur croirait alors recevoir un \emph{nouveau} message et ne réclamerait jamais celui
qui manque. Autre erreur : passer au message suivant après une perte, comme si le protocole
abandonnait ; il retransmet toujours.

\end{fichemethode}
