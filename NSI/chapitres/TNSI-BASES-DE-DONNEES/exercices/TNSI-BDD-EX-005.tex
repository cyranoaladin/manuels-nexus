\begin{exercice}{TNSI-BDD-EX-005}{1}{20}
Une médiathèque suit ses prêts avec le script suivant.
\begin{sql}
CREATE TABLE Emprunt(id INTEGER PRIMARY KEY, lecteur TEXT, cote TEXT, jours INTEGER);
INSERT INTO Emprunt VALUES (1, 'Amine', '843.9 DIO', 12);
INSERT INTO Emprunt VALUES (2, 'Lina', '004 KAN', 30);
INSERT INTO Emprunt VALUES (3, 'Omar', '843.9 DIO', 5);
INSERT INTO Emprunt VALUES (4, 'Sara', '510 BEN', 21);
\end{sql}
\begin{enumerate}
  \item Séparer les instructions de ce script en deux groupes : celles qui
    définissent la \textbf{structure} de la base, et celles qui y placent du
    \textbf{contenu}.
  \item Décrire la structure : citer les attributs, le domaine de chacun, et la
    clé primaire. Décrire ensuite le contenu : combien la table compte-t-elle de
    lignes après le script ?
  \item On considère la requête
    \begin{sql}
SELECT lecteur, jours FROM Emprunt WHERE jours > 10 ORDER BY jours DESC;
    \end{sql}
    Nommer chacun de ses quatre composants et dire à quoi il sert. Donner le
    résultat exact de la requête.
  \item Cette requête modifie-t-elle la structure ? Le contenu ? Justifier.
  \item Classer chacune des deux instructions suivantes comme modification de
    structure ou de contenu, et indiquer ce que devient le nombre de lignes et
    le nombre de colonnes après chacune :
    \begin{sql}
ALTER TABLE Emprunt ADD COLUMN rendu INTEGER;
DELETE FROM Emprunt WHERE jours < 10;
    \end{sql}
\end{enumerate}
\end{exercice}
