\begin{exercice}{TNSI-BDD-EX-004}{2}{20}
On dispose de la table :
\begin{sql}
CREATE TABLE Stock(id INTEGER PRIMARY KEY, produit TEXT, quantité INTEGER);
INSERT INTO Stock VALUES (1, 'Cahier', 40), (2, 'Stylo', 0), (3, 'Règle', 12);
\end{sql}
Écrire les requêtes SQL permettant, dans l'ordre, de :
\begin{enumerate}
  \item ajouter un produit \texttt{'Gomme'} avec une quantité de $25$ ;
  \item diminuer de $5$ la quantité de \texttt{'Cahier'} (sans réécrire la valeur numérique finale) ;
  \item supprimer tous les produits dont la quantité en stock est nulle.
\end{enumerate}
\end{exercice}
