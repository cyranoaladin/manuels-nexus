\begin{corrige}{TNSI-BDD-EX-003}
\begin{sql}
SELECT Eleve.nom, Note.matiere, Note.valeur
FROM Note
JOIN Eleve ON Note.id_eleve = Eleve.id
ORDER BY Note.valeur DESC;
\end{sql}
Le \texttt{JOIN} associe chaque note à l'élève correspondant via la clé étrangère \texttt{id\_eleve}, puis \texttt{ORDER BY ... DESC} trie le résultat de la note la plus haute à la plus basse.
\end{corrige}
