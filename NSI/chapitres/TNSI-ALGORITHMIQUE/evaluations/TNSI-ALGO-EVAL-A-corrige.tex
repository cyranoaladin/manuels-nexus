\textbf{Q1.} L'ABR obtenu a pour racine $10$, sous-arbre gauche enraciné en $5$ (avec $3$ à gauche et $7$ à droite), et sous-arbre droit enraciné en $15$ (avec $12$ à gauche).

\textbf{Q2.}

def minimum(arbre):
    while arbre.gauche is not None:
        arbre = arbre.gauche
    return arbre.valeur
\end{python}
Dans un ABR, chaque descente à gauche mène vers des valeurs plus petites ; la plus petite valeur est donc atteinte lorsqu'il n'y a plus de sous-arbre gauche.
\end{corrige}

\begin{corrige}{TNSI-ALGO-EVAL-A-EX3}
\textbf{Q1.} Sur l'ABR de racine $10$ :
\begin{itemize}
  \item \textbf{prefixe} (racine, gauche, droite) : $10, 5, 3, 7, 15, 12$ ;
  \item \textbf{infixe} (gauche, racine, droite) : $3, 5, 7, 10, 12, 15$ ;
  \item \textbf{suffixe} (gauche, droite, racine) : $3, 7, 5, 12, 15, 10$.
\end{itemize}
Le parcours infixe donne les valeurs \textbf{triees dans l'ordre croissant}. C'est la
propriete caracteristique de l'arbre binaire de recherche : tout ce qui est a gauche d'un
noeud lui est inferieur, tout ce qui est a droite lui est superieur, et l'infixe visite
justement le sous-arbre gauche, puis le noeud, puis le sous-arbre droit.

\textbf{Q2.} Le parcours en largeur utilise une \textbf{file} (structure premier entre,
premier sorti) : on defile un noeud, on l'enregistre, puis on enfile ses deux enfants.

\begin{python}
from collections import deque


def parcours_largeur(arbre):
    if arbre is None:
        return []
    valeurs, file = [], deque([arbre])
    while file:
        noeud = file.popleft()
        valeurs.append(noeud.valeur)
        if noeud.gauche is not None:
            file.append(noeud.gauche)
        if noeud.droite is not None:
            file.append(noeud.droite)
    return valeurs
\end{python}
Sur l'arbre de l'exercice : $10, 5, 15, 3, 7, 12$.

\textbf{Q3.} Les trois parcours en profondeur descendent completement dans un sous-arbre
avant de passer a l'autre : c'est exactement ce que fait la pile d'appels recursifs. Le
parcours en largeur, lui, doit revenir a des noeuds \textbf{voisins} avant de descendre,
ce que la pile d'appels ne permet pas ; il faut une file explicite, qui memorise les noeuds
dans l'ordre inverse de celui d'une pile.
\end{corrige}
