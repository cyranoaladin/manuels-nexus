\textbf{Q1.} Depuis \texttt{"P"} : on enfile \texttt{"P"}, on le défile et on enfile ses voisins \texttt{"Q"} puis \texttt{"R"} ; on défile \texttt{"Q"}, son voisin \texttt{"S"} n'est pas encore visité, on l'enfile ; on défile \texttt{"R"}, son voisin \texttt{"S"} est déjà visité. Ordre de visite : \texttt{P, Q, R, S}.

\textbf{Q2.} Depuis \texttt{"P"}, le parcours en profondeur descend d'abord dans
\texttt{"Q"}, puis dans son voisin \texttt{"S"}, puis dans \texttt{"R"} : ordre de visite
\texttt{P, Q, S, R}. C'est la structure auxiliaire qui distingue les deux parcours : une
\textbf{file} pour le parcours en largeur, une \textbf{pile} -- explicite, ou celle des
appels recursifs -- pour le parcours en profondeur.

\textbf{Q3.} Oui : \texttt{P} $\to$ \texttt{Q} $\to$ \texttt{S} $\to$ \texttt{R} $\to$ \texttt{P} est un cycle (chaque arête utilisée existe bien dans le graphe, et on revient au sommet de départ sans repasser par une même arête).

\textbf{Q4.} Un chemin existe entre deux sommets si et seulement si l'arrivee figure parmi
les sommets atteints par un parcours partant du depart :

def existe_chemin(graphe, depart, arrivee):

(un autre est \texttt{P} $\to$ \texttt{R} $\to$ \texttt{S}).
\end{corrige}

\begin{corrige}{TNSI-ALGO-EVAL-B-EX3}
\textbf{Q1.} L'ecriture naive appelle \lstinline{fibonacci(n-1)} et \lstinline{fibonacci(n-2)},
qui recalculent chacune les memes sous-termes : l'arbre des appels contient
\lstinline{fibonacci(n-2)} deux fois, \lstinline{fibonacci(n-3)} trois fois, et ainsi de
suite. Le nombre d'appels croit exponentiellement alors qu'il n'y a que $n$ valeurs
distinctes a connaitre.

\textbf{Q2.} La programmation dynamique memorise chaque terme des qu'il est calcule :

\begin{python}
def fibonacci_dynamique(n, memo=None):
    if memo is None:
        memo = {}
    if n < 2:
        return n
    if n not in memo:
        memo[n] = fibonacci_dynamique(n - 1, memo) + fibonacci_dynamique(n - 2, memo)
    return memo[n]
\end{python}
On obtient $F_{30} = 832\,040$.

\textbf{Q3.} Pour $n=20$, la version naive fait plus de treize mille appels ; la version
memorisee en fait moins de soixante, soit un rapport superieur a deux cents. Ce gain de
\textbf{temps} est paye par de la \textbf{memoire} : le dictionnaire conserve un terme par
rang, ce que la version naive ne fait pas.
\end{corrige}
