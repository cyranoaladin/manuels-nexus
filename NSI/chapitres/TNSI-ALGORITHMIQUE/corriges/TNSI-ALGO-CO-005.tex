\begin{python}
def maximum_dpr(liste):
    if len(liste) == 1:
        return liste[0]
    milieu = len(liste) // 2
    max_gauche = maximum_dpr(liste[:milieu])
    max_droite = maximum_dpr(liste[milieu:])
    return max(max_gauche, max_droite)
\end{python}
Le cas de base est une liste réduite à un seul élément : son maximum est cet élément lui-même, sans appel récursif. On suppose la liste non vide en entrée (une liste vide n'a pas de maximum).
\end{corrige}
