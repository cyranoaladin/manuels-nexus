## Traçabilité du transfert

`INVENTAIRE_DEPOT_DRIVE_20260909.json` répertorie les fichiers déposés, leurs identifiants Drive, leurs tailles et les empreintes SHA-256 calculées sur les fichiers locaux envoyés. La présence et les tailles sont relues dans les dossiers Drive ; une comparaison cryptographique après retéléchargement intégral n'est pas revendiquée.

Les archives ZIP locales ont passé leur contrôle CRC avant dépôt. Aucun script contenu dans une archive n'a été exécuté pendant cette opération.
