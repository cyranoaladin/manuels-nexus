# Glyphes LaTeX et artefact PDF NSI Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Supprimer les pertes de glyphes des PDF assemblés et garantir un artefact PDF NSI en CI, sans modifier la baseline visuelle.

**Architecture:** Le préflight PDF partagé devient fail-closed sur `Missing character:` et les sources utilisent les composants Nexus ou symboles LaTeX portables. La CI NSI compile toujours un spécimen, conserve la compilation ciblée des chapitres avec un pathspec racine correct et refuse un upload vide.

**Tech Stack:** Python 3.12, Pytest, GNU Make, LuaLaTeX, Poppler, GitHub Actions YAML.
