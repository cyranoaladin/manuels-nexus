# Dérivation des versions aménagées

`CANONICAL_OBJECT` → `AMENAGEMENT_PROFILE` → `AMENAGED_OBJECT`

- Objets aménagés : `10`
- Chapitres couverts : `10` / `17`
- `AMENAGED_WITHOUT_SOURCE` : `0`
- `AMENAGEMENT_MOVES_THE_TARGET` : `0`
- `AMENAGEMENT_DROPS_THE_TARGET` : `0`
- `PROFILE_DECLARED_NOT_APPLIED` : `0`
- `FRAGILE_TABULAR_MARKUP` : `0`

## Profils

- `AERATION` — Espacement vertical explicite, une tache par bloc visuel, tableaux plutot que paragraphes.
- `ALLEGEMENT_ENONCE` — Les phrases sont courtes et portent une information chacune. Le contexte narratif non necessaire a la tache est retire.
- `AMORCE_FOURNIE` — Le debut du code ou du raisonnement est donne. L'eleve poursuit au lieu de demarrer sur une page blanche.
- `REPONSE_FERMEE` — La production libre devient un choix entre reponses proposees, un texte a trous ou un tableau a completer. Ce qui est evalue reste la meme decision ; c'est sa forme d'expression qui est allegee.
- `RETRAIT_DOUBLE_TACHE` — Une seule operation cognitive a la fois : on ne demande pas de lire un programme ET de le modifier dans la meme question.
- `SEQUENCAGE` — L'enonce est decoupe en etapes numerotees, une consigne par etape. L'eleve n'a jamais a tenir plusieurs consignes en memoire.
