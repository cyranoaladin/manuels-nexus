\begin{corrige}{1SPE-EXPO-EX-044}
\begin{enumerate}
\item $M(0)=80$ : la masse initiale est de $80$ g.
\item $M(10)=80\,\mathrm{e}^{-3}\approx 4{,}0$ g.
\item
\[\frac{M(t+1)}{M(t)}=\mathrm{e}^{-0{,}3}\approx 0{,}741.\]
Chaque jour, la masse est donc multipliée par le même facteur, inférieur à $1$.
\item Le coefficient $-0{,}3$ est négatif : la fonction $t\mapsto \mathrm{e}^{-0{,}3t}$ est décroissante. Le modèle décrit une décroissance.
\end{enumerate}
