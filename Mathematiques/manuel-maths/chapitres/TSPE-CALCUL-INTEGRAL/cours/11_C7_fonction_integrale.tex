\section{La fonction intégrale est une primitive}

% ============================================================
% STRATE 1 — Démonstration exigible
% ============================================================

\theoreme{
Soit $f$ une fonction continue, \textbf{positive} et \textbf{croissante} sur $[a,b]$. La fonction $A$ définie sur $[a,b]$ par
\[
  A(x) = \int_a^x f(t)\,\mathrm{d}t
\]
est dérivable sur $[a,b]$, et $A' = f$ : $A$ est une primitive de $f$ sur $[a,b]$.
}

\demonstration{
Soit $x_0 \in [a,b[$ et $h>0$ tel que $x_0+h \leq b$. Par définition, $A(x_0+h) - A(x_0)$ est l'aire du domaine sous la courbe de $f$ entre $x_0$ et $x_0+h$ (relation de Chasles pour les aires).

Comme $f$ est croissante sur $[x_0, x_0+h]$, pour tout $t \in [x_0, x_0+h]$ : $f(x_0) \leq f(t) \leq f(x_0+h)$.

Par comparaison des aires (le domaine sous $f$ est compris entre deux rectangles de largeur $h$ et de hauteurs respectives $f(x_0)$ et $f(x_0+h)$) :
\[
  h\,f(x_0) \leq A(x_0+h) - A(x_0) \leq h\,f(x_0+h).
\]

En divisant par $h>0$ :
\[
  f(x_0) \leq \frac{A(x_0+h)-A(x_0)}{h} \leq f(x_0+h).
\]

Comme $f$ est continue en $x_0$, $f(x_0+h) \to f(x_0)$ quand $h \to 0^+$. Par le théorème des gendarmes, le taux d'accroissement de $A$ en $x_0$ (a droite) tend vers $f(x_0)$.

Un raisonnement analogue pour $h<0$ (taux d'accroissement a gauche) donne la même limite. Donc $A$ est dérivable en $x_0$ et $A'(x_0) = f(x_0)$.

Ce raisonnement est valable pour tout $x_0 \in [a,b]$ (aux bornes, on considere la derivabilite a droite ou a gauche uniquement), donc $A'=f$ sur $[a,b]$.
}

\theoreme[Conséquence]{
Si $F$ est une primitive quelconque de $f$ continue sur $[a,b]$, alors :
\[
  \int_a^b f(x)\,\mathrm{d}x = F(b) - F(a).
\]
}

\demonstration{
$A$ (définie ci-dessus) et $F$ sont deux primitives de $f$ sur $[a,b]$ : elles différent d'une constante $k$ (chapitre précédent), soit $F = A + k$.

Or $A(a) = \displaystyle\int_a^a f(t)\,\mathrm{d}t = 0$ (aire d'un domaine de largeur nulle). Donc $F(a) = A(a)+k = k$.

Ainsi $F(b) - F(a) = (A(b)+k) - k = A(b) = \displaystyle\int_a^b f(t)\,\mathrm{d}t$.
}

\margeAppui{
Notation : $F(b)-F(a)$ se note aussi $\big[F(x)\big]_a^b$. Ce résultat, etabli ici pour $f$ positive croissante, s'admet en general pour toute fonction continue.
}

\exemple{
Calculer $\displaystyle\int_0^2 x^2\,\mathrm{d}x$.

Une primitive de $x \mapsto x^2$ est $F(x) = \dfrac{x^3}{3}$.
\[
  \int_0^2 x^2\,\mathrm{d}x = F(2)-F(0) = \frac{8}{3} - 0 = \frac{8}{3}.
\]

% ============================================================
% STRATE 2 — Erreurs frequentes
% ============================================================

\erreurFrequente{
\textbf{Oublier l'hypothèse de croissance dans la démonstration.} La démonstration presentee ici suppose $f$ positive \emph{et} croissante (pour encadrer l'aire par deux rectangles). Le résultat final ($A'=f$) reste vrai pour toute fonction continue, mais sa démonstration generale (hors-programme) ne repose pas sur cet encadrement.
}
