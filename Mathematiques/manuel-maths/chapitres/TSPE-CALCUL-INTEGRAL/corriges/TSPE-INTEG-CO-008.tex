\begin{corrige}{TSPE-INTEG-EX-008}
On pose $u(x)=\ln(x+1)$, donc $u'(x)=\dfrac{1}{x+1}$, et $v'(x)=1$, donc $v(x)=x$.

Par integration par parties :
\[
  \int_0^1 \ln(x+1)\,\mathrm{d}x = \big[x\ln(x+1)\big]_0^1 - \int_0^1 \frac{x}{x+1}\,\mathrm{d}x.
\]

$\big[x\ln(x+1)\big]_0^1 = 1\times\ln 2 - 0 = \ln 2$.

Pour la seconde integrale, on ecrit $\dfrac{x}{x+1} = \dfrac{(x+1)-1}{x+1} = 1 - \dfrac{1}{x+1}$ :
\[
  \int_0^1 \frac{x}{x+1}\,\mathrm{d}x = \big[x - \ln(x+1)\big]_0^1 = (1-\ln 2) - 0 = 1-\ln 2.
\]

Finalement :
\[
  \int_0^1 \ln(x+1)\,\mathrm{d}x = \ln 2 - (1-\ln 2) = \boxed{2\ln 2 - 1}.
\]
\end{corrige}
