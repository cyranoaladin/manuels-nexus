\begin{exercice}{TCOMPL-ME-RE-C5-EX1}{1}{10}
Un élève résout $y'=2y+6$ et écrit directement $y(x)=C\,\mathrm{e}^{2x}$ comme solution générale, en oubliant le second membre. Vérifier, en calculant $y'(x)$ pour cette proposition, que ce n'est \textbf{pas} une solution de $y'=2y+6$. Proposer la solution correcte.

\begin{corrige}{TCOMPL-ME-RE-C5-EX1}
Pour $y(x)=C\mathrm{e}^{2x}$, on calcule $y'(x) = 2C\mathrm{e}^{2x} = 2y(x)$, donc $y'(x) - 2y(x) = 0 
eq 6$ : cette fonction vérifie $y'=2y$ (sans second membre), pas $y'=2y+6$. Elle n'est \textbf{pas} solution de l'équation demandée.

La solution particulière constante vérifie $0=2y_p+6$, soit $y_p=-3$. La solution générale correcte est $y(x) = C\mathrm{e}^{2x} - 3$.
\end{corrige}
