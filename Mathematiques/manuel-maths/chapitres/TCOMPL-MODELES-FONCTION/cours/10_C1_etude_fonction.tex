\section{Étudier une fonction pour modéliser un problème}

% ============================================================
% STRATE 1 — Dérivée, tableau de variation
% ============================================================

Une entreprise fabrique $x$ objets. Le coût moyen de production par objet (en euros) est modélisé, pour $x>0$, par :
\[
  f(x) = x + \frac{9}{x}.
\]

\propriete[Dérivée et sens de variation]{
La fonction $f$ est dérivable sur $]0,+\infty[$ et pour tout $x>0$ :
\[
  f'(x) = 1 - \frac{9}{x^2}.
\]
}

\exemple{
On résout $f'(x)=0$, soit $1 - \dfrac{9}{x^2}=0 \iff x^2=9 \iff x=3$ (car $x>0$). Pour $0<x<3$, $f'(x)<0$ ($f$ décroît) ; pour $x>3$, $f'(x)>0$ ($f$ croît). Le tableau de variation fait apparaître un minimum en $x=3$, avec $f(3) = 3+3=6$ euros.
}

\margeAppui{
Ce type de fonction (somme d'un terme proportionnel et d'un terme inversement proportionnel) modélise de nombreux coûts moyens : minimiser $f$ revient à trouver le meilleur compromis entre les deux effets.
}

\subsection*{Dériver après un changement affine de variable}

\propriete[Dérivée de $x\mapsto f(ax+b)$]{
Soit $f$ une fonction dérivable sur un intervalle ouvert $I$, et $a,b$ deux
réels. Sur un intervalle ouvert $J$ tel que $ax+b\in I$ pour tout $x\in J$,
la fonction $g$ définie par $g(x)=f(ax+b)$ est dérivable et
\[
  g'(x)=a\,f'(ax+b).
\]
On calcule d'abord $f'$, on y remplace la variable par $ax+b$, puis on
multiplie par $a$. Le facteur $a$ conserve son signe.
}

\demonstration{
Si $a=0$, la condition de domaine impose $b\in I$ : la fonction $g$ est
constante, égale à $f(b)$, et $g'(x)=0$.

Si $a\ne0$, une variation $h$ de $x$ produit une variation $ah$ de $ax+b$.
Pour $h\ne0$ suffisamment petit et $x\in J$, le taux de variation s'écrit
\[
  \frac{g(x+h)-g(x)}{h}
  =a\,\frac{f(ax+b+ah)-f(ax+b)}{ah}.
\]
Quand $h$ se rapproche de $0$, $ah$ se rapproche aussi de $0$.
Le quotient de droite se rapproche donc du nombre dérivé $f'(ax+b)$.
Le taux de variation de $g$ se rapproche ainsi de $a\,f'(ax+b)$.
}

\exemple{
Pour $g(x)=(1-2x)^2$, définie sur $\mathbb{R}$, on utilise la fonction carré
$f(t)=t^2$, de dérivée $f'(t)=2t$. Ici $a=-2$ et $b=1$, donc
\[
  g'(x)=-4(1-2x).
\]
Si le coefficient $a$ est nul, par exemple $g(x)=(0x+3)^2=9$,
la fonction est constante et sa dérivée est nulle.
}

\propriete[Nombre de solutions de $f(x)=k$]{
Une fonction strictement monotone sur un intervalle prend chaque valeur \textbf{au plus une fois}. Un tableau de variation avec plusieurs monotonies successives permet de dénombrer, sur chaque intervalle de monotonie, le nombre de solutions de $f(x)=k$ (une solution si $k$ est atteint sur cet intervalle, zéro sinon).
}

\exemple{
Pour $f(x)=x+\dfrac{9}{x}$ sur $]0,+\infty[$ : $f$ est strictement décroissante sur $]0,3]$ de $+\infty$ à $6$, puis strictement croissante sur $[3,+\infty[$ de $6$ à $+\infty$. Pour $k=10>6$, l'équation $f(x)=10$ admet donc \textbf{exactement deux} solutions (une sur chaque intervalle de monotonie) ; pour $k=6$, une seule solution ($x=3$) ; pour $k<6$, aucune solution.
}

\propriete[Valeurs approchées par balayage ou dichotomie]{
Lorsqu'une équation $f(x)=k$ n'admet pas de solution exacte simple, on cherche une \textbf{valeur approchée} : le \textbf{balayage} teste des valeurs régulièrement espacées jusqu'à encadrer un changement de signe de $f(x)-k$ ; la \textbf{dichotomie} affine cet encadrement en le divisant par deux à chaque étape.
}

\begin{python}
def dichotomie(f, a, b, precision):
    # f continue, f(a) et f(b) de signes opposes
    while b - a > precision:
        m = (a + b) / 2
        if f(a) * f(m) <= 0:
            b = m
        else:
            a = m
    return (a + b) / 2
\end{python}

\erreurFrequente{
\textbf{Appliquer la dichotomie sans vérifier le changement de signe.} La méthode suppose que $f(a)$ et $f(b)$ sont de signes opposés (théorème des valeurs intermédiaires) : sans cette hypothèse initiale vérifiée, l'algorithme peut converger vers une valeur qui n'est pas une solution de $f(x)=k$.
}
