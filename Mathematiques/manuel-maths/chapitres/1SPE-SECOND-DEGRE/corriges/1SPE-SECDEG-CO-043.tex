\begin{corrige}{1SPE-SECDEG-EX-043}

\textbf{1. Identification des coefficients.}

\commentaireMarge{Lire $a$, $b$, $c$ dans $ax^2+bx+c$.}

Le trinôme $f(x) = 3x^2 + 2x - 1$ est de la forme $ax^2 + bx + c$ avec :
\[a = 3, \quad b = 2, \quad c = -1.\]

\medskip
\textbf{2. Coordonnées du sommet.}

\commentaireMarge{Formule du sommet : $\alpha = -\dfrac{b}{2a}$.}

L'abscisse du sommet est :
\[\alpha = -\frac{b}{2a} = -\frac{2}{2 \times 3} = -\frac{1}{3}.\]

L'ordonnée du sommet est :
\[\beta = f\!\left(-\frac{1}{3}\right) = 3\times\left(-\frac{1}{3}\right)^2 + 2\times\left(-\frac{1}{3}\right) - 1 = \frac{3}{9} - \frac{2}{3} - 1 = \frac{1}{3} - \frac{2}{3} - \frac{3}{3} = -\frac{4}{3}.\]

Le sommet est $S\!\left(-\dfrac{1}{3}\,;\,-\dfrac{4}{3}\right)$.

\medskip
\textbf{3. Forme canonique.}

\commentaireMarge{$f(x)=a(x-\alpha)^2+\beta$.}

On a $a = 3$, $\alpha = -\dfrac{1}{3}$, $\beta = -\dfrac{4}{3}$, donc :
\[f(x) = 3\left(x + \frac{1}{3}\right)^2 - \frac{4}{3}.\]

\medskip
\textbf{4. Vérification de la forme factorisée.}

\commentaireMarge{Développer et simplifier pour vérifier.}

On développe $3\!\left(x+1\right)\!\left(x - \dfrac{1}{3}\right)$ :
\[3\!\left(x+1\right)\!\left(x - \frac{1}{3}\right) = 3\!\left(x^2 - \frac{1}{3}x + x - \frac{1}{3}\right) = 3\!\left(x^2 + \frac{2}{3}x - \frac{1}{3}\right) = 3x^2 + 2x - 1.\]

On retrouve bien $f(x)$. \hfill $\square$

\end{corrige}
