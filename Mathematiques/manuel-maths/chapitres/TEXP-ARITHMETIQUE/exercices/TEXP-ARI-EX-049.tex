\begin{exercice}{TEXP-ARI-EX-049}{3}{25}
Demontrer integralement le theoreme : \emph{si $f$ est deux fois derivable sur un intervalle $I$ avec $f'' \geq 0$ sur $I$, alors pour tous $a, x \in I$ : $f(x) \geq f(a) + f'(a)(x - a)$.}

\end{exercice}
