\begin{corrige}{TEXP-CTP-EX-021}

Posons $g(x) = \ln x - x + 1$ sur $\left]0, +\infty\right[$.

\commentaireMarge{$g'' < 0$ : $g$ est concave, donc son extremum est un maximum.}

$g'(x) = \dfrac{1}{x} - 1$ et $g''(x) = -\dfrac{1}{x^2} < 0$ : $g$ est concave.

$g'(x) = 0 \iff x = 1$ et $g(1) = 0$. Par concavite, $g(x) \leq g(1) = 0$, soit $\ln x \leq x - 1$.

\end{corrige}
