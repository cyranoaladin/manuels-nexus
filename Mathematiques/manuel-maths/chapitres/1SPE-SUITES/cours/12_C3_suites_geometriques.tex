\section{Suites géométriques}

% ============================================================
% STRATE 1 — Définitions et propriétés fondamentales
% ============================================================

\definition[5]{
Une suite $(u_n)$ est dite \textbf{géométrique} s'il existe un réel $q$, appelé
\textbf{raison}, tel que
\[
  u_{n+1} = q \cdot u_n \quad \text{pour tout } n \in \mathbb{N}.
\]
Autrement dit, on passe d'un terme au suivant en multipliant toujours par le même réel $q$.

\textbf{Remarque.} La valeur $q=0$ est autorisée : si $u_0\neq 0$, alors
$u_1=u_2=\cdots=0$. La suite nulle est donc géométrique (elle vérifie la
relation pour tout réel $q$). Lorsque les termes sont non nuls, on peut aussi
retrouver la raison par le quotient $q=\dfrac{u_{n+1}}{u_n}$ ; ce quotient est
une caractérisation conditionnelle, pas la définition générale.
}

\exemple{
La suite $(u_n)$ définie par $u_0 = 2$ et $u_{n+1} = 3 u_n$ est géométrique de raison $q = 3$.

On calcule : $u_0 = 2$, $u_1 = 6$, $u_2 = 18$, $u_3 = 54$.

On vérifie : $\dfrac{u_1}{u_0} = 3$, $\dfrac{u_2}{u_1} = 3$, $\dfrac{u_3}{u_2} = 3$.
}

\contreexemple{
La suite $(v_n)$ définie par $v_0 = 1$, $v_1 = 2$, $v_2 = 6$, $v_3 = 24$ n'est \emph{pas} géométrique :
$\dfrac{v_1}{v_0} = 2$ mais $\dfrac{v_2}{v_1} = 3$.
Le quotient de deux termes consécutifs n'est pas constant.
}

\propriete[2]{
Si $(u_n)$ est une suite géométrique de premier terme $u_0$ et de raison $q$,
alors, pour tout entier $n\geq1$ :
\[
  u_n = u_0 \times q^n.
\]
Pour $n=0$, le terme $u_0$ reste la donnée initiale ; cette formulation évite
d'avoir à donner un sens à $0^0$ lorsque $q=0$.

Plus généralement, si $n=p$, l'égalité $u_n=u_p$ est immédiate. Si $n>p$ :
\[
  u_n = u_p \times q^{n-p}.
\]
Si $q\neq 0$, cette dernière égalité reste valable pour tous entiers naturels
$n$ et $p$.
Cette formule s'appelle la \textbf{formule explicite} (ou terme général) de la suite géométrique.
}

\exemple{
Soit $(u_n)$ géométrique de raison $q = \dfrac{1}{2}$ et de premier terme $u_0 = 16$.

Formule explicite : $u_n = 16 \times \left(\dfrac{1}{2}\right)^n$.

On calcule directement : $u_4 = 16 \times \left(\dfrac{1}{2}\right)^4 = 16 \times \dfrac{1}{16} = 1$.

Si on connaît $u_2 = 4$ et $q = \dfrac{1}{2}$, on peut aussi écrire $u_n = 4 \times \left(\dfrac{1}{2}\right)^{n-2}$, ce qui donne le même résultat.
}

\contreexemple{
La suite $(w_n)$ définie par $w_n = 2^n + 1$ n'est pas géométrique :
$\dfrac{w_1}{w_0} = \dfrac{3}{2}$ mais $\dfrac{w_2}{w_1} = \dfrac{5}{3}$.
Le quotient n'est pas constant, même si $w_n$ contient une puissance de $2$.
}

% ============================================================
% STRATE 2 — Marge d'appui et erreurs fréquentes
% ============================================================

\margeAppui{
\textbf{Rappel :} arithmétique, on \emph{ajoute} $r$ ($u_0+nr$, points alignés, lien avec une fonction affine) ; géométrique, on \emph{multiplie} par $q$ ($u_0 \times q^n$, courbe en $q^n$, lien avec une fonction exponentielle).
}

\erreurFrequente{
\textbf{Utiliser un quotient lorsqu'un terme peut être nul.}

Pour montrer qu'une suite est géométrique, la voie générale consiste à établir
$u_{n+1}=q u_n$ avec un même réel $q$ pour tout $n$. On peut calculer
$\dfrac{u_{n+1}}{u_n}$ uniquement lorsque $u_n\neq 0$.

Si un terme est nul, le quotient correspondant n'est pas défini, mais la suite
peut tout de même être géométrique. C'est notamment le cas de la suite nulle et
d'une suite de raison $0$, qui devient nulle dès le rang suivant.
}

\erreurFrequente{
\textbf{Confusion entre $q^n$ et $q^{n-1}$ dans la formule explicite.}

Pour $n\geq1$, la formule est $u_n = u_0 \times q^n$ (exposant $n$,
indice du terme), \emph{pas} $u_0 \times q^{n-1}$. Au rang $0$, on conserve
la donnée initiale $u_0$ ; si $q=0$, la formule s'utilise pour $n\geq1$ afin
de ne pas introduire $0^0$.

L'exposant $n-1$ apparaît uniquement si on prend $u_1$ comme terme initial.
Si $q\neq0$, on a alors $u_n=u_1\times q^{n-1}$ pour tout $n\geq1$ ;
si $q=0$, on conserve $u_1$ au rang $1$ et on utilise cette formule pour
$n>1$.

\textbf{Moyen de ne pas confondre :} lorsque $q\neq0$, vérifier le cas $n=0$ :
$u_0\times q^0=u_0$. Lorsque $q=0$, vérifier plutôt le cas $n=1$ : on doit
obtenir $u_1=u_0\times0=0$.
}

\erreurFrequente{
\textbf{Représentation graphique : ne pas relier les points.}

Les termes d'une suite géométrique représentés par les points $(n\,;\,u_n)$ suivent une courbe en exponentielle, mais restent des points \emph{isolés} (la suite n'est définie que sur $\mathbb{N}$). On ne trace jamais de courbe continue pour représenter une suite.
}

% STRATE 3 — Approfondissement
% ============================================================

\approfondissement{
\textbf{Modèle exponentiel discret.}

Une suite géométrique de raison $q > 0$ et de premier terme $u_0 > 0$ peut être vue comme la version \emph{discrète} de la fonction exponentielle $f(x) = u_0 \times q^x$.

En effet, si on pose $f(n) = u_0 \times q^n$, les valeurs prises sur $\mathbb{N}$ coïncident avec les termes de la suite.

La différence fondamentale : la fonction exponentielle est définie sur $\mathbb{R}$ (on peut calculer $f(1{,}5)$), tandis que la suite n'est définie que pour des entiers naturels.

Ce lien est central en modélisation :
\begin{itemize}
  \item Un capital placé à intérêts composés à un taux $t$ par période évolue selon la suite géométrique de raison $q = 1 + t$ (voir Offre B de la situation d'accroche).
  \item Une population dont l'effectif est multiplié par $q$ chaque année suit le même modèle.
\end{itemize}

Sur des exemples avec $0<q<1$, un tableau de valeurs montre des termes
positifs de plus en plus petits : on conjecture qu'ils se rapprochent de $0$.
On parle de \emph{décroissance exponentielle discrète} (par exemple pour une
décroissance radioactive modélisée par périodes).

Sur des exemples avec $q>1$, les valeurs deviennent rapidement très grandes :
on conjecture un comportement vers $+\infty$. On parle de \emph{croissance
exponentielle discrète}.

Ces observations illustrent l'approche intuitive de la capacité C8 et restent
sans preuve formelle en Première.
}
