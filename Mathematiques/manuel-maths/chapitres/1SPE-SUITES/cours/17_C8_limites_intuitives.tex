\definition[Comportement à long terme — approche intuitive]{
Observer une suite sur un grand nombre de rangs permet de formuler une conjecture sur son comportement. Dans ce chapitre, cette sensibilisation reste \textbf{sans démonstration formelle} : on n'utilise ni définition avec des intervalles, ni théorème de convergence.

On distingue trois comportements :
\begin{itemize}
  \item une \textbf{limite finie} lorsque les termes semblent se rapprocher d'un même nombre ;
  \item une \textbf{limite infinie} lorsque les termes deviennent aussi grands que l'on veut, positivement ou négativement ;
  \item une \textbf{absence de limite} lorsque les termes ne se rapprochent pas d'un nombre et ne deviennent pas tous arbitrairement grands dans un même sens.
\end{itemize}
}

\exemple{
Pour $u_n=3+2^{-n}$, les valeurs $4$, $3{,}5$, $3{,}25$, $3{,}125$ se rapprochent de $3$ : on conjecture une limite finie égale à $3$.
}

\exemple{
Pour $v_n=n^2$, les termes deviennent arbitrairement grands : on conjecture une limite infinie égale à $+\infty$.
}

\exemple{
Pour $w_n=(-1)^n$, les termes alternent entre $1$ et $-1$ : la suite présente une absence de limite.
}

\erreurFrequente{
Une table de valeurs ou un graphique permet de conjecturer, pas de démontrer. Le programme de Première 2026-2027 exclut toute formalisation de la notion de limite.
}

\verifier{
\begin{itemize}
  \item Ai-je observé suffisamment de rangs sans me limiter aux trois premiers termes ?
  \item Ai-je distingué « se rapprocher d'un nombre », « devenir arbitrairement grand » et « osciller » ?
  \item Ai-je rédigé « on conjecture » lorsqu'aucune justification adaptée n'est fournie ?
\end{itemize}
}
