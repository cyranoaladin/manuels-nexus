\textbf{Diagnostic de l'erreur.}
Trois confusions sont fréquentes lorsqu'on observe les termes d'une suite :
croire que quelques termes suffisent à prouver un comportement, prendre la
moyenne de valeurs alternées pour une limite, ou confondre «~les termes
diminuent~» avec «~les termes se rapprochent de zéro~».

\textbf{Rappel ciblé.}
En Première, on commence par observer plusieurs termes, éventuellement à
l'aide d'un tableau, d'une calculatrice ou d'un programme. On décrit alors ce
que les valeurs suggèrent et on formule une \emph{conjecture} : limite finie,
limite infinie ou absence de limite. Une moyenne n'est pas une limite : les
termes eux-mêmes doivent se rapprocher de la valeur conjecturée. Cette étude
est menée sans démonstration formelle.

\textbf{Aide graduée.}
\coupDePouce{1}{Comparer la distance entre $a_n$ et $1$, puis regarder si
les valeurs de $b_n$ continuent à augmenter. Pour $(c_n)$, vérifier si les
termes finissent par rester proches d'une seule valeur.}

\textbf{Activité guidée.}
\begin{exercice}{1SPE-SUITES-RE-C8-GUIDE}{1}{8}
Pour $n\geqslant 1$, on définit
$a_n=1+2^{-n}$, $b_n=2^n$ et
$c_n=\dfrac{1+(-1)^n}{2}$. Voici leurs premiers termes :
\begin{itemize}
  \item $a_n$ : $1{,}5$ ; $1{,}25$ ; $1{,}125$ ; $1{,}0625$ ; $1{,}03125$ ;
  \item $b_n$ : $2$ ; $4$ ; $8$ ; $16$ ; $32$ ;
  \item $c_n$ : $0$ ; $1$ ; $0$ ; $1$ ; $0$.
\end{itemize}
\begin{enumerate}
  \item Calculer $a_6$, $b_6$ et $c_6$ pour prolonger chaque observation.
  \item Associer intuitivement chaque suite à l'un des comportements suivants :
  limite finie, limite infinie ou absence de limite.
  \item Rédiger chaque réponse comme une conjecture justifiée par les valeurs.
\end{enumerate}
\end{exercice}

% from fractions import Fraction
% assert 1 + Fraction(1, 2**6) == Fraction(65, 64)
% assert 2**6 == 64
% assert (1 + (-1)**6) // 2 == 1
% END-VERIFY

\begin{corrige}{1SPE-SUITES-RE-C8-GUIDE}
On obtient
\[
a_6=\dfrac{65}{64},\qquad b_6=64,\qquad c_6=1.
\]
Les nombres $a_n$ observés se rapprochent de $1$ : on conjecture une limite
finie égale à $1$. Les valeurs de $b_n$ augmentent rapidement : les calculs
suggèrent une limite infinie égale à $+\infty$. Enfin, les termes de $(c_n)$
restent alternativement égaux à $0$ et à $1$ ; ils ne se rapprochent pas
d'une valeur unique. On conjecture donc l'absence de limite.
\end{corrige}

\textbf{Exercice autonome.}
\begin{exercice}{1SPE-SUITES-RE-C8-AUTONOME}{1}{8}
Pour $n\geqslant 1$, on pose $p_n=5-3^{-n}$, $q_n=-n$ et
$r_n=(-2)^n$.
\begin{enumerate}
  \item Calculer, à la calculatrice ou avec un court programme, les six
  premiers termes de chaque suite.
  \item Classer intuitivement les trois suites parmi les comportements
  étudiés et justifier chaque conjecture par une observation précise.
\end{enumerate}
\end{exercice}

\[
\begin{aligned}
(p_n) :&\ \dfrac{14}{3},\ \dfrac{44}{9},\ \dfrac{134}{27},\ \dfrac{404}{81},\ \dfrac{1214}{243},\ \dfrac{3644}{729},\\
(q_n) :&\ -1,\ -2,\ -3,\ -4,\ -5,\ -6,\\
(r_n) :&\ -2,\ 4,\ -8,\ 16,\ -32,\ 64.
\end{aligned}
\]
Les valeurs de $(p_n)$ semblent se rapprocher de $5$ : on conjecture une
limite finie égale à $5$. Les valeurs de $(q_n)$ sont de plus en plus
négatives : on conjecture une limite infinie égale à $-\infty$. Les signes de
$(r_n)$ alternent et ses valeurs absolues augmentent : on conjecture l'absence
de limite.
\end{corrige}

\textbf{Revalidation.}
\begin{exercice}{1SPE-SUITES-RE-C8-REVALIDATION}{1}{5}
On observe les premiers termes des suites suivantes :
\[
(x_n) : 4{,}5;\ 4{,}25;\ 4{,}125;\ 4{,}0625,
\]
\[
(y_n) : 4;\ 7;\ 10;\ 13
\quad\text{et}\quad
(z_n) : -1;\ 1;\ -1;\ 1.
\]
Pour chacune, choisir le comportement que ces valeurs suggèrent et formuler
une conjecture. Aucun calcul de moyenne ne suffit à conclure.
\end{exercice}

\begin{corrige}{1SPE-SUITES-RE-C8-REVALIDATION}
Les termes observés de $(x_n)$ se rapprochent de $4$ : on conjecture une
limite finie égale à $4$. Ceux de $(y_n)$ augmentent régulièrement : on
conjecture une limite infinie égale à $+\infty$. Ceux de $(z_n)$ alternent
entre $-1$ et $1$ : on conjecture l'absence de limite.
\end{corrige}
