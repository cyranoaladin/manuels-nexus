\begin{exercice}{1SPE-SUITES-RE-C8-EX1}{1}{8}
Voici les premiers termes de trois suites :
\begin{itemize}
  \item $a_n$ : $1{,}5$ ; $1{,}25$ ; $1{,}125$ ; $1{,}0625$ ; $1{,}03125$ ;
  \item $b_n$ : $2$ ; $4$ ; $8$ ; $16$ ; $32$ ;
  \item $c_n$ : $0$ ; $1$ ; $0$ ; $1$ ; $0$.
\end{itemize}
Associer intuitivement chaque liste à : limite finie, limite infinie ou absence de limite. La réponse est attendue sans démonstration formelle.
\end{exercice}

\begin{corrige}{1SPE-SUITES-RE-C8-EX1}
Les termes de $(a_n)$ se rapprochent de $1$ : limite finie conjecturée égale à $1$. Les termes de $(b_n)$ grandissent sans borne : limite infinie conjecturée. Les termes de $(c_n)$ oscillent entre $0$ et $1$ : absence de limite conjecturée.
\end{corrige}

\begin{exercice}{1SPE-SUITES-RE-C8-RETEST}{1}{5}
Classer intuitivement $p_n=5-3^{-n}$, $q_n=-n$ et $r_n=(-2)^n$ parmi les trois comportements étudiés.
\end{exercice}

\begin{corrige}{1SPE-SUITES-RE-C8-RETEST}
On conjecture pour $(p_n)$ une limite finie égale à $5$, pour $(q_n)$ une limite infinie égale à $-\infty$, et pour $(r_n)$ une absence de limite car les signes alternent tandis que les valeurs absolues grandissent.
\end{corrige}
