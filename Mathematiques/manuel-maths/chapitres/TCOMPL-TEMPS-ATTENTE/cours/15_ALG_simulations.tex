\textbf{Le probleme.} Une machine tombe en panne avec la probabilite $p$ a
chaque cycle. Combien de cycles avant la premiere panne ? Et si le temps est
continu plutot que decoupe en cycles, quelle loi decrit l'attente ?

\propriete[Loi geometrique : repeter jusqu'au succes]{
On repete des epreuves de Bernoulli independantes de parametre $p \in\;]0\,;\,1]$
et l'on note $X$ le rang du premier succes. Alors $X$ suit la loi geometrique
de parametre $p$, et $E(X) = \dfrac{1}{p}$.

L'algorithme est la definition meme : tirer, compter, s'arreter au premier
succes. Entree : $p$, le nombre de repetitions, une graine. Sortie : la liste
des rangs obtenus.
}

\begin{python}
from random import Random

def simuler_geometrique(p, repetitions, graine):
    """Rangs du premier succes, pour des epreuves de Bernoulli de parametre p."""
    if not 0 < p <= 1 or repetitions < 1:
        raise ValueError("il faut 0 < p <= 1 et au moins une repetition")
    generateur = Random(graine)
    rangs = []
    for _ in range(repetitions):
        rang = 1
        while generateur.random() >= p:      # echec : on recommence
            rang = rang + 1
        rangs.append(rang)
    return rangs
\end{python}

\exemple{
Pour $p = 0{,}25$, dix mille repetitions et la graine $2024$, la moyenne des
rangs obtenus vaut $4{,}017\,1$, pour une esperance theorique
$\dfrac{1}{0{,}25} = 4$. Le plus grand rang observe est $30$ : la loi
geometrique n'est pas bornee, et de longues attentes arrivent.
}

\propriete[Loi exponentielle : transformer une loi uniforme]{
Si $U$ suit la loi uniforme sur $[0\,;\,1[$, alors
\[
  T = -\frac{\ln(1-U)}{\lambda}
\]
suit la loi exponentielle de parametre $\lambda$. En effet, pour $t \geq 0$,
\[
  P(T \leq t)
  = P\!\left(\ln(1-U) \geq -\lambda t\right)
  = P\!\left(1-U \geq \mathrm{e}^{-\lambda t}\right)
  = P\!\left(U \leq 1 - \mathrm{e}^{-\lambda t}\right)
  = 1 - \mathrm{e}^{-\lambda t},
\]
qui est bien la fonction de repartition de la loi exponentielle.
}

\margeAppui{
On ecrit $1-U$ et non $U$ pour que l'argument du logarithme ne puisse pas
valoir $0$ : le generateur peut rendre $0$, jamais $1$.
}

\begin{python}
from math import log

def simuler_exponentielle(lam, repetitions, graine):
    """Durees suivant la loi exponentielle de parametre lam."""
    if lam <= 0 or repetitions < 1:
        raise ValueError("lambda doit etre strictement positif")
    generateur = Random(graine)
    return [-log(1 - generateur.random()) / lam for _ in range(repetitions)]
\end{python}

\exemple{
\textbf{Demi-vie.} Pour $\lambda = 0{,}5$, la moyenne des dix mille durees
simulees vaut $2{,}055$, pour une esperance $\dfrac{1}{\lambda} = 2$. La
demi-vie, elle, est le temps $t_{1/2}$ tel que la moitie des atomes ait
disparu :
\[
  \mathrm{e}^{-\lambda t_{1/2}} = \frac{1}{2}
  \quad\Longleftrightarrow\quad
  t_{1/2} = \frac{\ln 2}{\lambda} = 1{,}386\ldots
\]
Sur la simulation, la proportion de durees superieures a $t_{1/2}$ vaut
$0{,}504\,6$ : tres proche de la moitie, comme annonce. La demi-vie n'est
\textbf{pas} l'esperance.
}

\erreurFrequente{
\textbf{Ecrire $-\ln(U)/\lambda$ au lieu de $-\ln(1-U)/\lambda$.} Les deux
suivent la meme loi, car $U$ et $1-U$ ont la meme loi uniforme. Mais le
generateur peut rendre $U = 0$, et $\ln 0$ n'existe pas : le programme
s'arrete sur une erreur. La seconde ecriture ne peut pas echouer.
}

\erreurFrequente{
\textbf{Confondre demi-vie et duree de vie moyenne.} La demi-vie vaut
$\dfrac{\ln 2}{\lambda}$, l'esperance $\dfrac{1}{\lambda}$ : la premiere est
environ $69\,\%$ de la seconde. La loi exponentielle est dissymetrique, sa
mediane n'est pas sa moyenne.
}
