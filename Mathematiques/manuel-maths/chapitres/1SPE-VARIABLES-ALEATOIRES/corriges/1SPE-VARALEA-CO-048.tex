\begin{corrige}{1SPE-VARALEA-EX-048}

\textbf{1.} $G = 8000$ si succès ($p = 0{,}6$), $G = -10000$ si échec ($p = 0{,}4$).

\medskip
\textbf{2.} $E(G) = 8000 \times 0{,}6 + (-10000) \times 0{,}4 = 4800 - 4000 = 800$~euros. L'investissement est intéressant en moyenne.

\medskip
\textbf{3.} $E(G^2) = 64\,000\,000 \times 0{,}6 + 100\,000\,000 \times 0{,}4 = 38\,400\,000 + 40\,000\,000 = 78\,400\,000$.

$V(G) = 78\,400\,000 - 640\,000 = 77\,760\,000$. $\sigma(G) \approx 8\,818$~euros. Le risque est élevé.

\medskip
\textbf{4.} Avec $5$ projets à $2\,000$~euros : gain par projet $= 1\,600$ (succès) ou $-2\,000$ (échec). L'espérance totale vaut $5 \times 160 = 800$~euros, comme pour le projet unique. Par indépendance, les variances s'ajoutent :
\[
V_{\mathrm{total}}
=5\left(1\,600^2\times0{,}6+2\,000^2\times0{,}4-160^2\right)
=15\,552\,000.
\]
Ainsi, $\sigma_{\mathrm{total}}=\sqrt{15\,552\,000}\approx 3\,944$~euros, soit l'écart type initial divisé par $\sqrt{5}$ environ : le risque est réduit par la diversification.

\end{corrige}
