\begin{corrige}{TSPE-PRIMEQ-EX-007}
Ici $a = -\dfrac{1}{2}$. Les solutions de $y'=ay$ sont $y(x) = C\mathrm{e}^{ax}$, soit $y(x) = C\mathrm{e}^{-x/2}$, $C \in \mathbb{R}$.

$y(0) = C = 2$. La solution cherchee est $\boxed{y(x) = 2\mathrm{e}^{-x/2}}$.
\end{corrige}
