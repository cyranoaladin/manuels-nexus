\begin{exercice}{TSPE-GEOESPACE-EX-052}{1}{14}
$ABCDEFGH$ est un cube. On travaille dans la base
$(\vec{AB},\vec{AD},\vec{AE})$.
\begin{enumerate}
  \item Décomposer $\vec{AG}$ dans cette base.
  \item Décomposer $\vec{EC}$, puis $\vec{HB}$, en détaillant le chemin
        d'arêtes utilisé.
  \item Décomposer $\vec{DF}$.
  \item Soit $I$ le milieu de $[GH]$. Décomposer $\vec{AI}$.
  \item Parmi les quatre vecteurs décomposés aux questions 1 à 3, deux
        sont-ils colinéaires ? Justifier.
\end{enumerate}
\end{exercice}
