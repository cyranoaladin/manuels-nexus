\section{Représentation paramétrique d'une droite}

% ============================================================
% STRATE 1 — Definition et methode
% ============================================================

\propriete{
Soit $\mathcal{D}$ la droite passant par $A(x_A,y_A,z_A)$ de vecteur directeur $\vec{u}\begin{pmatrix}a\\b\\c\end{pmatrix}$ (non nul). Un point $M(x,y,z)$ appartient a $\mathcal{D}$ si et seulement s'il existe $t \in \mathbb{R}$ tel que $\vec{AM}=t\vec{u}$, c'est-a-dire :
\[
  \begin{cases}
    x = x_A + ta \\
    y = y_A + tb \\
    z = z_A + tc
  \end{cases} \qquad (t \in \mathbb{R}).
\]
C'est une \textbf{representation parametrique} de $\mathcal{D}$.
}

\margeAppui{
Une droite admet une infinite de representations parametriques (selon le point choisi et le vecteur directeur, qui peut etre remplace par tout vecteur colineaire non nul).
}

\exemple{
Determiner une representation parametrique de la droite $\mathcal{D}$ passant par $A(1,2,-1)$ de vecteur directeur $\vec{u}\begin{pmatrix}2\\-1\\3\end{pmatrix}$.
\[
  \begin{cases}
    x = 1+2t \\
    y = 2-t \\
    z = -1+3t
  \end{cases} \qquad (t \in \mathbb{R}).
\]

Le point $B(5,0,5)$ appartient-il a $\mathcal{D}$ ? On resout $1+2t=5 \Rightarrow t=2$ ; on verifie : $2-2=0$ \checkmark, $-1+3\times2=5$ \checkmark. Donc $B \in \mathcal{D}$.

% BEGIN-VERIFY
% t = 2
% x = 1+2*t; y = 2-t; z = -1+3*t
% assert (x,y,z) == (5,0,5)
% END-VERIFY
}

% ============================================================
% STRATE 2 — Erreurs frequentes
% ============================================================

\erreurFrequente{
\textbf{Utiliser une valeur de $t$ differente pour chaque coordonnee.} Pour verifier qu'un point appartient a $\mathcal{D}$, il faut trouver une \textbf{unique} valeur de $t$ qui convienne simultanement aux trois equations. Si les valeurs de $t$ obtenues sont differentes, le point n'appartient pas a la droite.
}
