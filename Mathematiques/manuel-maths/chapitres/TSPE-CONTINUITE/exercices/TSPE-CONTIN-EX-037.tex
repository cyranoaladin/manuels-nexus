\begin{exercice}{TSPE-CONTIN-EX-037}{1}{10}
Soit $(u_n)$ definie par $u_0 = 1$ et $u_{n+1} = \dfrac{u_n}{2} + 1$.
\begin{enumerate}
  \item Calculer les quatre premiers termes apres $u_0$.
  \item Montrer que $[1\,;2]$ est stable par $f : x \mapsto \dfrac{x}{2} + 1$, puis que $1 \leq u_n \leq 2$ pour tout $n$.
  \item Montrer que $(u_n)$ est croissante, puis qu'elle converge.
  \item Determiner sa limite de deux facons : par l'equation $f(\ell) = \ell$, puis en etudiant la suite $t_n = 2 - u_n$.
\end{enumerate}
\end{exercice}
