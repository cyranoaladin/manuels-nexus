\begin{exercice}{TSPE-CONTIN-EX-018}{1}{10}
Une fonction $f$ est continue sur $[-3\,;4]$. Son tableau de variations est le suivant :
\begin{itemize}
  \item $f$ est strictement croissante sur $[-3\,;-1]$, avec $f(-3) = -2$ et $f(-1) = 5$ ;
  \item $f$ est strictement decroissante sur $[-1\,;2]$, avec $f(2) = -4$ ;
  \item $f$ est strictement croissante sur $[2\,;4]$, avec $f(4) = 1$.
\end{itemize}
\begin{enumerate}
  \item Determiner le nombre de solutions de l'equation $f(x) = 0$ sur $[-3\,;4]$, en justifiant sur chaque intervalle.
  \item Meme question pour $f(x) = 3$.
  \item Combien l'equation $f(x) = 6$ admet-elle de solutions ? Justifier sans calcul.
\end{enumerate}
\end{exercice}
