\textbf{Approfondissement — Vers la Terminale.}
\begin{corrige}{1SPE-TRIGO-EX-024}
$\cos(x) = \cos\!\left(\dfrac{\pi}{4}\right) \iff x = \dfrac{\pi}{4} + 2k\pi \quad \text{ou} \quad x = -\dfrac{\pi}{4} + 2k\pi$.
Dans $]-\pi \,;\, \pi]$, les solutions sont $S = \left\{-\dfrac{\pi}{4} \,;\, \dfrac{\pi}{4}\right\}$.
\end{corrige}
