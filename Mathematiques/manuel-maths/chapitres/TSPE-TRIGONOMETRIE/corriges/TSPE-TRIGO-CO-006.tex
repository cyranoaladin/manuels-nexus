\begin{corrige}{TSPE-TRIGO-EX-006}

\textbf{Q1.} $f'(x) = -\sin x - \cos x$. $f'(x) = 0 \iff \sin x = -\cos x$, ce qui equivaut a $\tan x = -1$ (lorsque $\cos x 
eq 0$). Sur $[-\pi,\pi]$, les solutions sont $x=-\dfrac{\pi}{4}$ et $x=\dfrac{3\pi}{4}$.

\textbf{Q2.} $f\!\left(-\dfrac{\pi}{4}\right) = \cos\!\left(-\dfrac{\pi}{4}\right) - \sin\!\left(-\dfrac{\pi}{4}\right) = \dfrac{\sqrt{2}}{2} - \left(-\dfrac{\sqrt{2}}{2}\right) = \sqrt{2}$.

$f\!\left(\dfrac{3\pi}{4}\right) = \cos\!\left(\dfrac{3\pi}{4}\right) - \sin\!\left(\dfrac{3\pi}{4}\right) = -\dfrac{\sqrt{2}}{2} - \dfrac{\sqrt{2}}{2} = -\sqrt{2}$.

\textbf{Q3.} D'apres l'hypothese admise, $f$ decroit sur $\left[-\pi,-\dfrac{\pi}{4}\right]$, croit sur $\left[-\dfrac{\pi}{4},\dfrac{3\pi}{4}\right]$, puis decroit sur $\left[\dfrac{3\pi}{4},\pi\right]$.

Aux bornes : $f(-\pi) = \cos(-\pi)-\sin(-\pi) = -1$ et $f(\pi) = \cos(\pi)-\sin(\pi) = -1$.

Le tableau de variations comporte donc les valeurs successives $f(-\pi)=-1$ (decroissance depuis $-\pi$), $f\!\left(-\dfrac{\pi}{4}\right)=\sqrt{2}$ (maximum local), $f\!\left(\dfrac{3\pi}{4}\right)=-\sqrt{2}$ (minimum local), puis $f(\pi)=-1$.

Le maximum de $f$ sur $[-\pi,\pi]$ est $\sqrt{2}$, atteint en $x=-\dfrac{\pi}{4}$. Le minimum est $-\sqrt{2}$, atteint en $x=\dfrac{3\pi}{4}$.

\end{corrige}
