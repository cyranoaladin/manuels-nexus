\begin{corrige}{1SPE-GEOREP-EX-014}

\commentaireMarge{Deux droites sont perpendiculaires si $a_1 a_2 + b_1 b_2 = 0$.}

$a_1 a_2 + b_1 b_2 = 3 \times 1 + (-1) \times 3 = 3 - 3 = 0$.

Donc $\mathcal{D}_1 \perp \mathcal{D}_2$.

\end{corrige}
