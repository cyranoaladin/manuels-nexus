\begin{corrige}{1SPE-GEOREP-EX-048}

On pose $x^2 + y^2 + Ax + By + C = 0$.

$A(0;0)$ : $C = 0$. $B(4;0)$ : $16 + 4A = 0$, $A = -4$. $C(0;6)$ : $36 + 6B = 0$, $B = -6$.

Équation : $x^2 + y^2 - 4x - 6y = 0$, soit $(x-2)^2 + (y-3)^2 = 13$.

Centre $\Omega(2 ; 3)$, rayon $r = \sqrt{13}$.

\end{corrige}
