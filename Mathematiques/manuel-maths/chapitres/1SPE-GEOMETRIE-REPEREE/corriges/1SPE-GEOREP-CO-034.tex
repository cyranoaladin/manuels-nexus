\begin{corrige}{1SPE-GEOREP-EX-034}

$d(O, \mathcal{D}) = \dfrac{|3 \times 0 + 4 \times 0 - 15|}{\sqrt{9 + 16}} = \dfrac{15}{5} = 3$.

$d = 3 < 5 = r$ : la droite est \textbf{sécante} au cercle (deux points d'intersection).
