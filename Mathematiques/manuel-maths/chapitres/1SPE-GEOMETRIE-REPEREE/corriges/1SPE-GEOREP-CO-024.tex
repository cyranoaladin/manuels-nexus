\begin{corrige}{1SPE-GEOREP-EX-024}

\commentaireMarge{Le centre est le milieu de $[AB]$, le rayon est $AB/2$.}

Milieu : $I(3 ; 5)$.

$AB = \sqrt{(5-1)^2 + (7-3)^2} = \sqrt{16 + 16} = 4\sqrt{2}$.

Rayon : $r = \dfrac{4\sqrt{2}}{2} = 2\sqrt{2}$, donc $r^2 = 8$.

Équation : $\boxed{(x - 3)^2 + (y - 5)^2 = 8}$.
