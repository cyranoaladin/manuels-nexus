\begin{corrige}{1SPE-GEOREP-EX-001}

\commentaireMarge{Calculer le coefficient directeur.}

\textbf{} Le coefficient directeur est $m = \dfrac{7 - 3}{5 - 1} = \dfrac{4}{4} = 1$.

L'équation réduite est $y - 3 = 1(x - 1)$, soit $y = x + 2$.

L'équation cartésienne est $\boxed{x - y + 2 = 0}$.

Vérification : $A$ : $1 - 3 + 2 = 0$ \checkmark. $B$ : $5 - 7 + 2 = 0$ \checkmark.

\end{corrige}
