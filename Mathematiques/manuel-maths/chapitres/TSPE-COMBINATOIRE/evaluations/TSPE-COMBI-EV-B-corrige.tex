\begin{corrige}{TSPE-COMBI-EV-B-EX3}
Soit $E$ un ensemble a $n$ elements, $a \in E$ fixe. On classe les parties a $k$ elements de $E$ selon qu'elles contiennent $a$ ou non :
\begin{itemize}
  \item parties contenant $a$ : choisir les $k-1$ autres elements parmi les $n-1$ restants, soit $\dbinom{n-1}{k-1}$ ;
  \item parties ne contenant pas $a$ : choisir les $k$ elements parmi les $n-1$ restants, soit $\dbinom{n-1}{k}$.
\end{itemize}
Ces deux categories sont disjointes et couvrent toutes les parties a $k$ elements : par le principe additif, $\dbinom{n}{k} = \dbinom{n-1}{k-1}+\dbinom{n-1}{k}$.
\end{corrige}
